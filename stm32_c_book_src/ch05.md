## 5.1 Serial Communication Basics

**UART** (Universal Asynchronous Receiver/Transmitter) sends bytes one bit at a time with no shared clock. Both ends must agree on the settings beforehand; the most common is **115200 baud, 8 data bits, no parity, 1 stop bit (8N1)**.

A frame for one byte: start bit (0), 8 data bits LSB-first, stop bit (1). At 115200 baud one bit lasts 8.68 µs and one byte (10 bits) 86.8 µs, so throughput is about **11.5 KB/s**.

| Term | Meaning |
|---|---|
| UART / USART | USART can also do synchronous mode, SmartCard, IrDA, LIN |
| TX / RX | Cross them: **MCU TX → device RX**, MCU RX ← device TX |
| Common ground | Always connect GND between the boards |
| Logic level | 3.3 V on STM32. RS-232 (±12 V) needs a MAX3232; RS-485 needs a transceiver |

> [hw] Virtual COM Port | On the Nucleo, **USART2 (PA2 TX / PA3 RX)** is wired to the ST-LINK, which presents it to your PC as a COM port (`/dev/ttyACM0` on Linux, `COMx` on Windows). No extra cable is needed to print debug output.

## 5.2 Three Ways to Transfer Data

| Method | HAL call | CPU usage | Use when |
|---|---|---|---|
| **Polling** | `HAL_UART_Transmit()` / `Receive()` | CPU waits in the function | Quick tests, short messages |
| **Interrupt** | `HAL_UART_Transmit_IT()` / `Receive_IT()` | CPU interrupted per byte | Moderate rates, simple designs |
| **DMA** | `HAL_UART_Transmit_DMA()` / `Receive_DMA()` | CPU free until the transfer completes | High rates, background streaming |

```c Polling transmit and receive
uint8_t msg[] = "Hello STM32\r\n";
HAL_UART_Transmit(&huart2, msg, sizeof(msg) - 1, 100);     /* 100 ms timeout */

uint8_t c;
if (HAL_UART_Receive(&huart2, &c, 1, 10) == HAL_OK) {
    /* got a character */
}
```

## 5.3 Interrupt-Driven Reception

Receiving by polling forces you to call `Receive()` often enough not to miss bytes. With interrupts you arm the receiver for one byte and re-arm in the callback, pushing bytes into a ring buffer.

```c Interrupt RX with a ring buffer
#define RX_BUF_SIZE 128                 /* power of two */
static uint8_t  rx_byte;
static uint8_t  rx_buf[RX_BUF_SIZE];
static volatile uint16_t head, tail;

void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
  if (huart->Instance == USART2) {
    rx_buf[head] = rx_byte;
    head = (head + 1) & (RX_BUF_SIZE - 1);
    HAL_UART_Receive_IT(&huart2, &rx_byte, 1);       /* re-arm */
  }
}

int rx_get(void)                        /* returns -1 when empty */
{
  if (head == tail) return -1;
  uint8_t c = rx_buf[tail];
  tail = (tail + 1) & (RX_BUF_SIZE - 1);
  return c;
}
/* Start once: HAL_UART_Receive_IT(&huart2, &rx_byte, 1); */
```

> [tip] Single producer, single consumer | A ring buffer needs no locking when exactly one context (the ISR) writes `head` and one (main) writes `tail`. Make both `volatile` and use a power-of-two size so wrapping is a cheap mask.

## 5.4 Retargeting printf

Debug output is far easier with `printf`. In CubeIDE the C library calls `_write()`; override it to send through USART2:

```c printf over USART2 (add to a USER CODE section in main.c)
#include <stdio.h>

int _write(int file, char *ptr, int len)
{
  HAL_UART_Transmit(&huart2, (uint8_t *)ptr, len, HAL_MAX_DELAY);
  return len;
}

/* usage */
printf("T=%d.%02d C  ADC=%u\r\n", t / 100, t % 100, adc);
```

> [warn] printf has a cost | `printf` is slow, blocks while transmitting (115200 baud = about 87 µs per character) and can use several KB of Flash and stack. **Never call it from an ISR**, and remove or reduce it in time-critical code.

## 5.5 DMA: Moving Data Without the CPU

A **DMA controller** is a small bus master that copies data between memory and peripherals on its own. The CPU only sets up the transfer (source, destination, length) and is interrupted when it is done - or when half is done.

The F446 has **DMA1** and **DMA2**, each with 8 **streams**; every stream selects one of 8 **channels** (request sources). The mapping is fixed by the hardware - for example, USART2_RX = DMA1 Stream 5 Channel 4 and USART2_TX = DMA1 Stream 6 Channel 4. CubeMX picks these for you; look at the *DMA Settings* tab of the peripheral.

| Setting | Options | Notes |
|---|---|---|
| Direction | Peripheral→Memory, Memory→Peripheral, Memory→Memory (DMA2 only) | RX is P→M, TX is M→P |
| Mode | **Normal** (one shot) or **Circular** (wraps forever) | Circular suits continuous ADC and UART RX |
| Increment address | Memory yes, peripheral no | Peripheral register address stays fixed |
| Data width | Byte / Half-word / Word | Match the peripheral (ADC 12-bit = half-word) |
| Priority | Low…Very High | Matters when several streams compete |

```c Transmit with DMA
static uint8_t tx_buf[64];
volatile uint8_t tx_busy;

void console_send(const char *s)
{
  while (tx_busy) { }                              /* wait for previous */
  size_t n = strlen(s);
  memcpy(tx_buf, s, n);
  tx_busy = 1;
  HAL_UART_Transmit_DMA(&huart2, tx_buf, n);       /* returns immediately */
}

void HAL_UART_TxCpltCallback(UART_HandleTypeDef *huart)
{
  if (huart->Instance == USART2) tx_busy = 0;
}
```

> [warn] Buffer lifetime | The DMA reads the buffer **after** the function returns. Do not pass a local (stack) array that goes out of scope; use static or global buffers and do not modify them until the completion callback.

## 5.6 DMA RX with Idle-Line Detection

You rarely know how many bytes will arrive. The UART **IDLE** flag is set when the line has been quiet for one frame time after reception - the end of a message. HAL wraps it into `HAL_UARTEx_ReceiveToIdle_DMA()`.

```c Variable-length messages with DMA + IDLE
#define DMA_BUF_SIZE 128
static uint8_t dma_buf[DMA_BUF_SIZE];
static uint8_t cmd[DMA_BUF_SIZE];
static volatile uint16_t cmd_len;
static volatile uint8_t  cmd_ready;

/* USER CODE BEGIN 2 */
HAL_UARTEx_ReceiveToIdle_DMA(&huart2, dma_buf, DMA_BUF_SIZE);
__HAL_DMA_DISABLE_IT(huart2.hdmarx, DMA_IT_HT);     /* no half-transfer events */
/* USER CODE END 2 */

void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t size)
{
  if (huart->Instance == USART2) {
    memcpy(cmd, dma_buf, size);                      /* hand over a copy */
    cmd_len   = size;
    cmd_ready = 1;
    HAL_UARTEx_ReceiveToIdle_DMA(&huart2, dma_buf, DMA_BUF_SIZE);   /* restart */
    __HAL_DMA_DISABLE_IT(huart2.hdmarx, DMA_IT_HT);
  }
}
```

Handle errors too: an **overrun** (ORE - a byte arrived before the previous one was read), **framing** (wrong baud rate) and **noise** errors stop reception until you restart it. Implement `HAL_UART_ErrorCallback` and re-arm the receiver.

```c Recover from UART errors
void HAL_UART_ErrorCallback(UART_HandleTypeDef *huart)
{
  if (huart->Instance == USART2) {
    HAL_UARTEx_ReceiveToIdle_DMA(&huart2, dma_buf, DMA_BUF_SIZE);
    __HAL_DMA_DISABLE_IT(huart2.hdmarx, DMA_IT_HT);
  }
}
```

## 5.7 DMA with the ADC

Continuous ADC sampling is the classic DMA use-case. A circular buffer is filled forever; callbacks fire at the half and full points so you can process one half while DMA fills the other (**ping-pong** processing).

```c ADC1 + DMA circular buffer (Mode = Circular, half-word)
#define ADC_BUF_LEN 256
static uint16_t adc_buf[ADC_BUF_LEN];

/* USER CODE BEGIN 2 */
HAL_ADC_Start_DMA(&hadc1, (uint32_t *)adc_buf, ADC_BUF_LEN);
/* USER CODE END 2 */

void HAL_ADC_ConvHalfCpltCallback(ADC_HandleTypeDef *hadc) { process(&adc_buf[0],              ADC_BUF_LEN / 2); }
void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef *hadc)     { process(&adc_buf[ADC_BUF_LEN / 2], ADC_BUF_LEN / 2); }
```

Keep `process()` short or just set a flag; heavy processing belongs in `main()`.

## 5.8 A Command Console

With RX working, build a tiny shell. It turns the board into something you can control and test interactively - invaluable for the rest of the book.

```c Minimal command parser
static void handle_command(char *line)
{
  if (strcmp(line, "led on") == 0) {
    HAL_GPIO_WritePin(LD2_GPIO_Port, LD2_Pin, GPIO_PIN_SET);
    printf("OK\r\n");
  } else if (strcmp(line, "led off") == 0) {
    HAL_GPIO_WritePin(LD2_GPIO_Port, LD2_Pin, GPIO_PIN_RESET);
    printf("OK\r\n");
  } else if (strncmp(line, "pwm ", 4) == 0) {
    int pct = atoi(line + 4);
    if (pct >= 0 && pct <= 100) { set_brightness_percent((uint8_t)pct); printf("OK\r\n"); }
    else printf("ERR range 0-100\r\n");
  } else if (strcmp(line, "adc") == 0) {
    printf("adc=%u\r\n", adc_read());
  } else {
    printf("ERR unknown command. Try: led on|off, pwm N, adc\r\n");
  }
}

/* in the main loop */
if (cmd_ready) {
  cmd_ready = 0;
  cmd[cmd_len] = '\0';
  cmd[strcspn((char *)cmd, "\r\n")] = '\0';          /* strip line ending */
  handle_command((char *)cmd);
}
```

> [warn] Validate all input | Check lengths and ranges before using received data. A command parser without bounds checks is a classic source of buffer overflows and crashes.
