Academic & Industry Bibliography

References, Specifications & Data Sheets

Curated, authoritative technical references for students, university instructors, and embedded firmware engineers covering Zephyr RTOS internals, STMicroelectronics hardware documentation, ARM Cortex-M architecture, and international industrial standards.

1. Zephyr Project Official Documentation

Zephyr Project Official Documentation (v3.7 / LTS)
Comprehensive guides on Kernel services, DeviceTree bindings, Kconfig search, driver APIs, and architecture ports.
https://docs.zephyrproject.org/latest/
Zephyr Devicetree API Reference
Complete specification of compile-time node macros (DT_NODELABEL, DT_ALIAS, DT_PROP, DT_FOREACH_PROP_ELEM).
https://docs.zephyrproject.org/latest/build/dts/api/api.html
Devicetree Specification (Release v0.4)
The official open-hardware standard for device trees originally standardized by devicetree.org.
https://www.devicetree.org/specifications/
MCUboot Secure Bootloader Documentation
Image formats, dual-slot swap protocol, cryptographic signing with imgtool, and rollback recovery.
https://docs.mcuboot.com/

2. STMicroelectronics Hardware Manuals & Application Notes

UM1724: STM32 Nucleo-64 Boards User Manual
Schematics, jumper settings (JP5, JP6), ST-LINK/V2-1 pinouts, virtual COM port routing, and power supply options.
STMicroelectronics DocID UM1724 (PDF)
RM0368: STM32F401xB/C and STM32F401xD/E Advanced ARM-based 32-bit MCUs Reference Manual
Deep dive into STM32 clock trees (RCC), GPIO alternate function registers (AFR), DMA controllers, timers (TIM2-5), and I2C/SPI interfaces.
STMicroelectronics DocID RM0368 (PDF)
RM0444: STM32G0x1 Advanced ARM-based 32-bit MCUs Reference Manual
Reference manual covering Cortex-M0+ architectural specifics, low-power stop modes, and FDCAN peripherals.
STMicroelectronics DocID RM0444 (PDF)
AN2606: STM32 Microcontroller System Memory Boot Mode
Details on the factory ROM bootloader protocol across USART, USB DFU, I2C, and SPI.
STMicroelectronics DocID AN2606 (PDF)

3. ARM Cortex-M Core & Architecture References

ARM Cortex-M4 Devices Generic User Guide
ARM DUI 0553A: Detailed coverage of Cortex-M register banks, exception handling, NVIC priority grouping, SysTick timer, and Memory Protection Unit (MPU).
Yiu, Joseph: "The Definitive Guide to ARM Cortex-M3 and Cortex-M4 Processors" (3rd Edition, Newnes)
The authoritative book on real-time task switching, context stacking, exception models, and fault debugging.

4. Industry Standards & Protocols

ISO 11898-1:2015: Road Vehicles — Controller Area Network (CAN)
Standard specification for Data Link Layer and physical signaling in Classical CAN and CAN FD.
Bluetooth Core Specification v5.3 / v5.4
Bluetooth Special Interest Group (SIG): Host Controller Interface (HCI), GAP, and GATT architectures.
POSIX IEEE Std 1003.1-2017
Standard operating system interface definitions implemented by Zephyr's POSIX compatibility subsystem (pthreads, semaphores, clocks).
