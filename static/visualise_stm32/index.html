What the firmware image looks like—and what startup loads

An ELF file records sections and load/run addresses. A raw .bin is a flat byte image; the linker script and startup code determine where each section goes.

Key distinction: firmware code normally executes directly from Flash; startup copies only initialized writable data to its SRAM run address and clears .bss. The displayed initial MSP value is an example at the top of SRAM1; SRAM2, when used, can be a separate linker memory region. Exact addresses and layout come from the selected MCU linker script.
