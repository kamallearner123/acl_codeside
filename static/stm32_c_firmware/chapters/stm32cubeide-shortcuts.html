Keyboard Shortcuts for Code Traversal

Move through STM32 HAL code, find declarations and types, and step through firmware without losing your place.

⌨️ Linux key bindings
🧭 Navigation, editing & debugging

Code navigation

ShortcutAction
F3Open the declaration of the selected function, variable or symbol.
Ctrl + ClickNavigate to a symbol's definition or declaration.
Ctrl + Shift + ROpen a resource or file by name.
Ctrl + Shift + TOpen a type, such as a struct or HAL definition.
Alt + ← / →Go back or forward through editor navigation history.
Ctrl + OShow the current file's outline and jump to a member.
Ctrl + LJump to a specific line number.
Ctrl + HSearch across files and projects.

Editing and finding code

ShortcutAction
Ctrl + SpaceShow code completion and suggestions.
Ctrl + Shift + FFormat the current source file.
Ctrl + DDelete the current line.
Ctrl + /Toggle a line comment.
Ctrl + FFind text in the current file.
Ctrl + Z / Ctrl + YUndo / redo the last edit.

Build and debug

ShortcutAction
Ctrl + BBuild the project.
F11Start debugging the selected project or launch configuration.
Ctrl + F11Run the selected project, when supported by its launch configuration.
F5 / F6 / F7Step into / step over / step return while debugging.
F8Resume execution.
Ctrl + F2Terminate the active debug session.

Quick HAL debugging workflow

  1. Double-click the editor gutter beside a line to set a breakpoint.
  2. Press F11 to launch a debug session and wait for the target to halt.
  3. Use F6 to execute one source line at a time, or F5 to enter a function when debug symbols and source are available.
  4. Inspect values in the Variables view, then press F8 to resume.

For example, place a breakpoint on HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET); to inspect the program immediately before the LED output changes.

Key bindings can vary

STM32CubeIDE versions, Linux desktop shortcuts and custom key schemes may change these bindings. Check or change them under Window → Preferences → General → Keys.
