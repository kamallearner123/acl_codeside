Mini Projects & Capstone

Consolidate everything: five mini projects with clear acceptance criteria, then a capstone - a CAN-connected environmental data logger with a command console, watchdog and a test plan.

9.1 From Exercises to Products

A product is more than working code on your desk. It must start reliably, survive faults, report what it is doing and be testable. This chapter gives five mini projects, then a capstone that combines every skill from the book.

Work in vertical slices
Get a minimal version of the whole system running first (sensor -> processing -> output). Only then refine each part. A rough end-to-end system finds integration problems early.

9.2 Five Mini Projects

# Project Skills used Acceptance criteria
1 Traffic light controller with pedestrian button GPIO, EXTI, timers, state machine Pedestrian request is served within one cycle; no HAL_Delay in the logic
2 PWM fan controller ADC, PWM, timers Fan speed follows a potentiometer smoothly; duty is clamped to 20-100 %
3 UART command console USART, DMA, ring buffer Commands led on/off, adc, help; no byte lost at 115200 baud under load
4 I2C weather display I2C, BME280, SSD1306 Temperature, humidity and pressure update at 1 Hz without flicker
5 Servo scanner PWM, servo, SPI/I2C sensor Servo sweeps 0-180 degrees, sensor value logged per angle

Pattern: a table-driven state machine

C Traffic light state machine 
typedef enum { ST_GREEN, ST_YELLOW, ST_RED, ST_PED } state_t;

typedef struct {
    uint32_t duration_ms;
    state_t  next;
} state_def_t;

static const state_def_t table[] = {
    [ST_GREEN]  = { 8000, ST_YELLOW },
    [ST_YELLOW] = { 2000, ST_RED    },
    [ST_RED]    = { 6000, ST_GREEN  },
    [ST_PED]    = { 5000, ST_GREEN  },
};

static volatile bool ped_request;
static state_t state = ST_GREEN;
static uint32_t entered;

void traffic_task(void)
{
    uint32_t now = HAL_GetTick();
    if (now - entered < table[state].duration_ms) return;

    state = (state == ST_RED && ped_request) ? ST_PED : table[state].next;
    if (state == ST_GREEN) ped_request = false;
    entered = now;
    lights_apply(state);
}

void HAL_GPIO_EXTI_Callback(uint16_t pin)
{
    if (pin == B1_Pin) ped_request = true;
}

Pattern: ring buffer for UART

C Lock-free single-producer single-consumer ring buffer 
#define RB_SIZE 256u            /* power of two */

typedef struct {
    uint8_t buf[RB_SIZE];
    volatile uint16_t head;     /* written by the producer (ISR) */
    volatile uint16_t tail;     /* written by the consumer (main) */
} rb_t;

static inline bool rb_put(rb_t *r, uint8_t b)
{
    uint16_t next = (r->head + 1u) & (RB_SIZE - 1u);
    if (next == r->tail) return false;         /* full */
    r->buf[r->head] = b;
    r->head = next;
    return true;
}

static inline bool rb_get(rb_t *r, uint8_t *b)
{
    if (r->head == r->tail) return false;      /* empty */
    *b = r->buf[r->tail];
    r->tail = (r->tail + 1u) & (RB_SIZE - 1u);
    return true;
}

9.3 Capstone: CAN-Connected Environmental Data Logger

Build a node that measures its environment, shows it locally, accepts commands over UART and publishes data on a CAN bus to a second node (a second Nucleo or a USB-CAN adapter).

Requirements

ID Requirement
R1 Sample BME280 (I2C) at 1 Hz and an analog light sensor (ADC + DMA) at 10 Hz
R2 Show the latest values on an SSD1306 OLED, refreshed at 2 Hz
R3 Send a CAN frame ID 0x100 every second: int16 temp x10, uint16 humidity x10, uint16 light
R4 UART console (DMA + idle line) with commands status, rate <ms>, led, fault
R5 A PWM-driven status LED: slow breathing = OK, fast blink = sensor error
R6 Independent watchdog (IWDG) with a 2 s timeout; the main loop must feed it only when all tasks ran
R7 HardFault handler stores the fault frame in backup SRAM and reports it after the next reboot
R8 No blocking delays in the main loop; every ISR is shorter than 20 microseconds

Architecture

  • Interrupt layer - DMA complete callbacks, UART idle line, timer tick, CAN RX; each only sets a flag or pushes to a buffer.
  • Service layer - sensor, display, console, can_link, led modules, each with init() and step().
  • Supervisor - runs every step(), checks the health bits and feeds the watchdog.
C Cooperative scheduler skeleton 
typedef struct {
    void (*step)(void);
    uint32_t period_ms;
    uint32_t last;
    uint32_t ok_flag;
} task_t;

static task_t tasks[] = {
    { sensor_step,  1000, 0, 1u << 0 },
    { adc_step,      100, 0, 1u << 1 },
    { display_step,  500, 0, 1u << 2 },
    { can_step,     1000, 0, 1u << 3 },
    { console_step,   10, 0, 1u << 4 },
    { led_step,       20, 0, 1u << 5 },
};
#define ALL_OK ((1u << 6) - 1u)

void supervisor_run(void)
{
    static uint32_t seen;
    uint32_t now = HAL_GetTick();

    for (size_t i = 0; i < sizeof tasks / sizeof tasks[0]; i++) {
        if (now - tasks[i].last >= tasks[i].period_ms) {
            tasks[i].last = now;
            tasks[i].step();
            seen |= tasks[i].ok_flag;
        }
    }
    if (seen == ALL_OK) {
        HAL_IWDG_Refresh(&hiwdg);
        seen = 0;
    }
}
C Packing the CAN payload 
void can_send_environment(int16_t t10, uint16_t h10, uint16_t light)
{
    CAN_TxHeaderTypeDef h = { .StdId = 0x100, .IDE = CAN_ID_STD,
                              .RTR = CAN_RTR_DATA, .DLC = 6 };
    uint8_t d[6] = { t10 & 0xFF, t10 >> 8, h10 & 0xFF, h10 >> 8,
                     light & 0xFF, light >> 8 };
    uint32_t mailbox;
    if (HAL_CAN_AddTxMessage(&hcan1, &h, d, &mailbox) != HAL_OK) {
        can_tx_errors++;
    }
}
Feed the watchdog from one place
If an ISR or a single task refreshes the IWDG, a hung main loop is never detected. Refresh only in the supervisor, only after every task proved it ran.

9.4 Test Plan and Definition of Done

Test Method Pass condition
Sensor accuracy Compare with a reference thermometer Within +/- 1 degree C
CAN timing Logic analyzer / CAN adapter timestamps Frame every 1000 ms +/- 5 ms
Console under load Paste 1000 bytes of commands at 115200 No lost or corrupted command
Watchdog Add an infinite loop with the fault command Board resets within 2.5 s and reports the reason
HardFault Dereference NULL via the fault command Reboot message shows PC and source line
Power cycle x50 Script or manual Boots into a working state every time
ISR timing GPIO toggle on the analyzer Each ISR under 20 microseconds

Review checklist

  • Every register-touching variable that is shared with an ISR is volatile and accessed atomically where needed.
  • No HAL_Delay or blocking calls in ISRs or in the main loop logic.
  • All HAL return values are checked or deliberately ignored with a comment.
  • Pin map, clock tree and bus addresses are documented in a README.
  • The project builds from a clean checkout with a single command or IDE action.
Make it portfolio-ready
Add a photo, a wiring diagram, a logic-analyzer screenshot of the CAN frame, and a short README. Recruiters look for evidence that you can debug and verify, not only code.
