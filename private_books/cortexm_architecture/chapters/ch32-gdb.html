Chapter 32 • Debug & Tools

GDB

A vendor-neutral look at GDB, with the STM32F446 as a worked example.

⏱️ Reading Time: 30 minutes
🛠️ Lab: Lab 32
🎯 Topics: GDB

32.1 GDB and the Debug Chain

GDB is the GNU debugger. For an embedded target it talks to a GDB server (OpenOCD, ST-LINK GDB server, J-Link GDB server, pyOCD) over TCP; the server talks to the probe, which uses SWD.

TEXT Chain 
arm-none-eabi-gdb --> TCP :3333 --> OpenOCD --> ST-LINK --> SWD --> Cortex-M

32.2 A Minimal Session

BASH Start 
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg
arm-none-eabi-gdb build/firmware.elf
(gdb) target extended-remote :3333
(gdb) monitor reset halt
(gdb) load
(gdb) break main
(gdb) continue

32.3 Essential Commands

Command Purpose
break file.c:42 / tbreak func Breakpoints
continue, next, step, finish Run control
info registers, p $pc, p/x $sp Registers
x/16wx 0x20000000 Examine memory
bt, frame 1, info locals Stack and variables
watch var, rwatch var Data watchpoints (DWT)
display var Show after each stop
monitor reset halt Probe commands

32.4 Reading Peripheral Registers

TEXT Examine hardware directly 
(gdb) x/4wx 0x40020000          # GPIOA registers
(gdb) set *(unsigned int *)0x40020014 = 0x20     # write ODR
(gdb) p/x *(unsigned int *)0xE000ED28            # CFSR

With an SVD file (Cortex-Debug in VS Code) you see named peripherals and bit fields.

32.5 Debugging Faults

TEXT After a HardFault 
(gdb) p/x *(unsigned int *)0xE000ED28       # CFSR
(gdb) p/x *(unsigned int *)0xE000ED38       # BFAR
(gdb) x/8wx $sp                              # stacked frame
(gdb) info symbol 0x08001234                 # map stacked PC to a function
(gdb) list *0x08001234                       # show the source line

32.6 Build for Debugging

  • -g3 -Og keeps variables inspectable; -O2 may optimise them away.
  • Keep the ELF with symbols; flash the binary derived from it.
  • Use -ffunction-sections for size, but keep frame pointers when stack unwinding is poor.

32.7 Scripting

TEXT .gdbinit 
target extended-remote :3333
monitor reset halt
define hf
  p/x *(unsigned int *)0xE000ED28
  p/x *(unsigned int *)0xE000ED38
end
