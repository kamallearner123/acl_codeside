Module 6: Functions, ABI & Modular System Architecture

Understand how functions execute on CPU silicon: stack frames, calling conventions (AAPCS vs System V AMD64), function inlining, static functions for encapsulation, and clean header contracts.

⏱️ Estimated Reading: 50 min
🎯 Standard: C11 / C17 / C23
🛠️ Environments: Linux POSIX + Bare-Metal ARM
⚡ MISRA C:2012 Rule 8.2, 8.4, 17.7 Aligned

6.1 The Application Binary Interface (ABI) & Calling Conventions

When one function calls another, the compiler must adhere to a standardized Application Binary Interface (ABI) defining which CPU registers pass arguments, which registers must be preserved across calls, and how the return value is provided:

Convention Argument Registers Return Register Callee-Saved (Preserved) Caller-Saved (Scratch)
ARM AAPCS (32-bit Cortex-M) r0, r1, r2, r3 (remainder on stack) r0 (or r0-r1 for 64-bit) r4-r11, SP r0-r3, r12, LR
System V AMD64 (Linux x86_64) rdi, rsi, rdx, rcx, r8, r9 rax (or rax:rdx) rbx, rsp, rbp, r12-r15 r10, r11, rax, rcx, rdx...

6.2 Function Inlining: Performance vs. Flash Bloat

Small functions (e.g., bit manipulation, register reads) can be declared static inline in header files. This replaces the function call with the actual instructions, eliminating call overhead, parameter register shuffling, and stack frame generation:

CStatic Inline Header Pattern
#ifndef BIT_MATH_H
#define BIT_MATH_H

#include <stdint.h>

/* static inline avoids multiple definition errors across compilation units */
static inline uint32_t count_trailing_zeros(uint32_t val) {
    if (val == 0) return 32U;
    return (uint32_t)__builtin_ctz(val);
}

#endif /* BIT_MATH_H */

6.3 Opaque Pointers & True Encapsulation in C

In professional embedded and systems development, you achieve object-oriented encapsulation through opaque pointers (also called the Pimpl idiom or handle pattern). Consumers cannot access or depend on internal struct layout:

Cring_buffer.h (Public Interface)
#ifndef RING_BUFFER_H
#define RING_BUFFER_H

#include <stddef.h>
#include <stdbool.h>
#include <stdint.h>

/* Forward declaration: struct internals are completely hidden */
typedef struct RingBuffer RingBuffer_t;

RingBuffer_t* ring_buffer_create(size_t capacity);
void          ring_buffer_destroy(RingBuffer_t *rb);
bool          ring_buffer_push(RingBuffer_t *rb, uint8_t byte);
bool          ring_buffer_pop(RingBuffer_t *rb, uint8_t *byte);

#endif /* RING_BUFFER_H */
