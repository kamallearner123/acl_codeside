Module 10: Structures, Unions, Alignment & Bitfields

Analyze struct padding, natural alignment rules, hardware bitfields, union type-punning, and robust endianness-independent protocol serialization.

⏱️ Duration: 60m
🎯 System: Memory Layout, Bus Faults, MISRA C:2012
⚡ Architecture: ARM Cortex-M / Linux x86_64

10.1 Struct Memory Layout, Padding & Natural Alignment

CPUs read memory over 32-bit (4-byte) or 64-bit (8-byte) data buses. To optimize bus cycles, the C compiler aligns struct members to addresses that are multiples of their natural type size. If you declare variables in suboptimal order, the compiler inserts invisible padding bytes: 

Suboptimal Struct Layout (12 Bytes Total):
+---------+-------------------+---------+-------------------+
| a (u8)  | [3 PAD BYTES]     | b (u32) | c (u16) | [2 PAD] |
+---------+-------------------+---------+-------------------+
  Byte 0       Byte 1-3         Byte 4-7    Byte 8-9  Byte 10-11

Optimized Struct Layout (8 Bytes Total - Zero Padding!):
+---------+---------+---------+
| b (u32) | c (u16) | a (u8)  | [1 PAD]
+---------+---------+---------+
  Byte 0-3  Byte 4-5  Byte 6    Byte 7
Cstruct_padding_demo.c
#include <stdio.h>
#include <stddef.h>
#include <stdint.h>

struct BadLayout {
    uint8_t  a; /* 1 byte */
    /* 3 padding bytes */
    uint32_t b; /* 4 bytes */
    uint16_t c; /* 2 bytes */
    /* 2 padding bytes */
};

struct GoodLayout {
    uint32_t b; /* 4 bytes */
    uint16_t c; /* 2 bytes */
    uint8_t  a; /* 1 byte */
    uint8_t  pad; /* Explicit 1 byte */
};

int main(void) {
    printf("BadLayout size:  %zu bytes (Offset of b: %zu)\n", 
           sizeof(struct BadLayout), offsetof(struct BadLayout, b));
    printf("GoodLayout size: %zu bytes (Offset of b: %zu)\n", 
           sizeof(struct GoodLayout), offsetof(struct GoodLayout, b));
    return 0;
}

10.2 Packed Structs vs Explicit Wire Serialization

Engineers often use __attribute__((packed)) to map network packets directly to structs. However, packed structs cause severe performance penalties or bus faults on ARM because multi-byte fields are no longer aligned!

MISRA C:2012 Rule 1.3 / CERT C EXP36-C: Never pass a pointer to a packed struct member to a function expecting an aligned pointer (e.g. uint32_t*). The hardware may crash with an unaligned access fault!

10.3 Bitfields: Register Mapping & Portability Hazards

C bitfields allow packing arbitrary bit lengths into words:

Chardware_bitfields.c
#include <stdint.h>

/* Example: UART Control Register 1 (CR1) */
typedef struct {
    uint32_t send_break      : 1;  /* Bit 0 */
    uint32_t receiver_wakeup : 1;  /* Bit 1 */
    uint32_t receiver_enable : 1;  /* Bit 2 */
    uint32_t tx_enable       : 1;  /* Bit 3 */
    uint32_t idlen_interrupt : 1;  /* Bit 4 */
    uint32_t rxne_interrupt  : 1;  /* Bit 5 */
    uint32_t tc_interrupt    : 1;  /* Bit 6 */
    uint32_t txe_interrupt   : 1;  /* Bit 7 */
    uint32_t pe_interrupt    : 1;  /* Bit 8 */
    uint32_t parity_selection: 1;  /* Bit 9: 0=Even, 1=Odd */
    uint32_t parity_control  : 1;  /* Bit 10 */
    uint32_t word_length     : 1;  /* Bit 11: 0=8-bit, 1=9-bit */
    uint32_t uart_enable     : 1;  /* Bit 12 */
    uint32_t reserved        : 19; /* Bits 13..31 */
} USART_CR1_Bits_t;

typedef union {
    uint32_t         reg_value;
    USART_CR1_Bits_t bits;
} USART_CR1_t;
Portability Warning: The C standard specifies that bitfield layout order (LSB to MSB vs MSB to LSB) is implementation-defined. For portable wire protocols (e.g. TCP/IP headers, CAN frames), prefer explicit bitmask operations (&, |, <<) over bitfields!

10.4 Real-Time Industrial Case: Telemetry Packet Serialization with CRC16

In telemetry and IoT systems, binary packets must be encoded with strict endianness (Network Big-Endian or Little-Endian) without depending on compiler struct packing:

Csafe_wire_protocol.c
#include <stdint.h>
#include <stddef.h>

typedef struct {
    uint16_t sync_word;    /* 0xAA55 */
    uint8_t  msg_type;
    uint8_t  seq_num;
    uint32_t timestamp_ms;
    int16_t  temperature_c_x100;
    uint16_t crc16;
} TelemetryPacket_t;

/* Serialize telemetry packet to raw bytes safely (Endian-Independent) */
size_t serialize_telemetry(const TelemetryPacket_t *pkt, uint8_t *dest, size_t max_buf) {
    if (max_buf < 12) return 0;

    dest[0] = (uint8_t)(pkt->sync_word >> 8);
    dest[1] = (uint8_t)(pkt->sync_word & 0xFF);
    dest[2] = pkt->msg_type;
    dest[3] = pkt->seq_num;

    /* Big-endian 32-bit timestamp */
    dest[4] = (uint8_t)(pkt->timestamp_ms >> 24);
    dest[5] = (uint8_t)(pkt->timestamp_ms >> 16);
    dest[6] = (uint8_t)(pkt->timestamp_ms >> 8);
    dest[7] = (uint8_t)(pkt->timestamp_ms & 0xFF);

    /* Big-endian 16-bit signed temperature */
    dest[8] = (uint8_t)((uint16_t)pkt->temperature_c_x100 >> 8);
    dest[9] = (uint8_t)((uint16_t)pkt->temperature_c_x100 & 0xFF);

    /* Big-endian 16-bit CRC */
    dest[10] = (uint8_t)(pkt->crc16 >> 8);
    dest[11] = (uint8_t)(pkt->crc16 & 0xFF);

    return 12;
}
