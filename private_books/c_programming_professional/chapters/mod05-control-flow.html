Module 5: Control Flow, Branch Prediction & Finite State Machines

Design deterministic control logic, optimize CPU pipeline branch penalties, leverage compiler jump tables, and build hierarchical Finite State Machines (FSMs) for real-time firmware.

⏱️ Estimated Reading: 55 min
🎯 Standard: C11 / C17 / C23
🛠️ Environments: Linux POSIX + Bare-Metal ARM
⚡ MISRA C:2012 Rule 14.1, 15.3 Aligned

5.1 Switch-Case Lowering: Jump Tables vs. Binary Search Trees

The C switch statement is compiled in two distinct ways depending on the density and span of case values:

1. Jump Table (O(1) Execution)

When case values are contiguous (e.g. 0, 1, 2, 3), GCC emits an array of code pointers in .rodata. The CPU uses an indirect branch: jmp *table[idx] in constant time, ideal for real-time packet parsers.

2. Decision Tree / Binary Search (O(log N))

When case values are sparse (e.g. 10, 1000, 500000), a jump table would waste excessive flash memory. The compiler generates cascading cmp and conditional branch instructions.

5.2 Deterministic Finite State Machine (FSM) Implementation

Real-time firmware (automotive ECU, motor control, communication stacks) must never block in arbitrary loops. Instead, event-driven state machines process one state transition at a time:

CTable-Driven Finite State Machine in C
#include <stdio.h>
#include <stdint.h>

typedef enum {
    STATE_IDLE,
    STATE_RX_HEADER,
    STATE_RX_PAYLOAD,
    STATE_VERIFY_CRC,
    STATE_ERROR,
    STATE_COUNT
} ProtocolState_t;

typedef enum {
    EVENT_BYTE_RCVD,
    EVENT_TIMEOUT,
    EVENT_CRC_OK,
    EVENT_CRC_FAIL
} ProtocolEvent_t;

typedef ProtocolState_t (*StateHandler_t)(ProtocolEvent_t event, uint8_t byte);

static ProtocolState_t on_idle(ProtocolEvent_t ev, uint8_t byte) {
    if (ev == EVENT_BYTE_RCVD && byte == 0xAA) {
        return STATE_RX_HEADER;
    }
    return STATE_IDLE;
}

static ProtocolState_t on_rx_header(ProtocolEvent_t ev, uint8_t byte) {
    if (ev == EVENT_TIMEOUT) return STATE_ERROR;
    /* Process packet header ... */
    return STATE_RX_PAYLOAD;
}

/* Fast dispatch table with function pointers */
static const StateHandler_t StateTable[STATE_COUNT] = {
    [STATE_IDLE]        = on_idle,
    [STATE_RX_HEADER]   = on_rx_header,
    /* ... remaining handlers ... */
};

void run_protocol_engine(ProtocolState_t *current_state, ProtocolEvent_t event, uint8_t byte) {
    if (*current_state < STATE_COUNT && StateTable[*current_state]) {
        *current_state = StateTable[*current_state](event, byte);
    }
}

5.3 Branch Prediction & GNU __builtin_expect

Modern superscalar CPUs speculatively execute instructions down predicted branch paths. A branch misprediction incurs a pipeline flush of 10 to 20 CPU cycles. In high-frequency interrupt service routines, you can guide the compiler:

CLikely & Unlikely Branch Optimization Macros
#define likely(x)   __builtin_expect(!!(x), 1)
#define unlikely(x) __builtin_expect(!!(x), 0)

void handle_packet_fastpath(const uint8_t *buf, size_t len) {
    /* 99.9% of packets are valid; prioritize layout for non-null buffer */
    if (unlikely(buf == NULL || len == 0)) {
        log_hardware_error();
        return;
    }
    process_stream(buf, len);
}
