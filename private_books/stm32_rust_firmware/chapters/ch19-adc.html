Chapter 19 • Peripherals

ADC: Sensor Acquisition

Read analog signals, convert units with newtypes and filter noise with fixed-size averages.

⏱️ Reading Time: 35 minutes
🛠️ Lab: Analog acquisition
🎯 Topics: ADC

19.1 ADC Recap

The F446 has a 12-bit ADC with reference voltage VREF+ (3.3 V on a Nucleo). A raw count maps linearly:

TEXT ADC conversion 
V = raw * VREF / 4095

19.2 Single Conversion

RUST Read PA0 (ADC1 channel 0) 
use stm32f4xx_hal::adc::{config::{AdcConfig, SampleTime}, Adc};

let gpioa = dp.GPIOA.split();
let pin = gpioa.pa0.into_analog();
let mut adc = Adc::adc1(dp.ADC1, true, AdcConfig::default());

let raw: u16 = adc.convert(&pin, SampleTime::Cycles_480);
let mv = (raw as u32 * 3300) / 4095;
defmt::info!("raw={} mv={}", raw, mv);

into_analog() consumes the digital pin object, so you cannot accidentally also drive the pin as an output.

Sample time matters
High-impedance sources (a potentiometer through a long wire, an NTC with a large resistor) need a long sample time. 480 cycles is the safest choice for slow signals.

19.3 Typed Units

Mixing raw counts, millivolts and degrees is a classic bug. Use newtypes:

RUST Newtypes prevent unit mix-ups 
#[derive(Clone, Copy)] struct Raw(u16);
#[derive(Clone, Copy)] struct MilliVolt(u32);
#[derive(Clone, Copy)] struct DeciCelsius(i32);

impl Raw {
    fn to_mv(self, vref_mv: u32) -> MilliVolt { MilliVolt(self.0 as u32 * vref_mv / 4095) }
}

// TMP36: 750 mV at 25 C, 10 mV per degree
fn tmp36(mv: MilliVolt) -> DeciCelsius {
    DeciCelsius((mv.0 as i32 - 500) )   // 10 mV per C = 1 mV per 0.1 C
}

A function taking MilliVolt cannot be called with a Raw; the compiler enforces it.

19.4 Filtering

Single samples are noisy. Use a fixed-size moving average with no heap:

RUST Moving average over N samples 
struct Avg<const N: usize> { buf: [u16; N], idx: usize, filled: usize }

impl<const N: usize> Avg<N> {
    const fn new() -> Self { Self { buf: [0; N], idx: 0, filled: 0 } }
    fn push(&mut self, x: u16) -> u16 {
        self.buf[self.idx] = x;
        self.idx = (self.idx + 1) % N;
        if self.filled < N { self.filled += 1; }
        let sum: u32 = self.buf[..self.filled].iter().map(|&v| v as u32).sum();
        (sum / self.filled as u32) as u16
    }
}

The buffer length is a const generic, so the size is known at compile time, and indexing is checked by % N.

19.5 Internal Channels and Calibration

The internal temperature sensor and VREFINT are read like any other channel. VREFINT (about 1.2 V) lets you compute the real supply voltage and correct readings when the battery sags: VDDA = 3.3 V * VREFINT_CAL / raw_vrefint.

19.6 Continuous Sampling with DMA

For several channels or audio-rate sampling use scan mode plus DMA circular buffers (chapter 21). The main loop reads a stable half of the buffer while hardware fills the other half.
