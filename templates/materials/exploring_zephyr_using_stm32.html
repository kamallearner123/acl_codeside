Install system dependencies

Update the package index and install the tools and Python packages required for the Zephyr development environment.

sudo apt update

sudo apt install -y \
    git cmake ninja-build gperf \
    device-tree-compiler \
    python3-dev python3-venv python3-pip \
    python3-setuptools python3-wheel \
    wget
