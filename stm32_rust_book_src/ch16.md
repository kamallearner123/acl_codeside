## 16.1 UART in Rust

The Nucleo routes USART2 to the ST-LINK Virtual COM Port: **PA2 = TX**, **PA3 = RX**. The terminal on your PC sees whatever you write.

```rust Serial console at 115200 baud
use core::fmt::Write;
use stm32f4xx_hal::{prelude::*, serial::Config};

let gpioa = dp.GPIOA.split();
let serial = dp.USART2.serial(
    (gpioa.pa2, gpioa.pa3),
    Config::default().baudrate(115_200.bps()),
    &clocks,
).unwrap();
let (mut tx, mut rx) = serial.split();

writeln!(tx, "boot v{}", env!("CARGO_PKG_VERSION")).ok();   // core::fmt works on any Write
```

`serial()` takes the pins by value and checks at compile time that PA2/PA3 are valid TX/RX pins for USART2. You cannot pass a pin that is not wired to that peripheral.

## 16.2 Polling Read and Write

```rust Blocking echo
use nb::block;                       // turns a non-blocking call into a blocking one

loop {
    let byte = block!(rx.read()).unwrap();   // wait for a byte
    block!(tx.write(byte)).ok();             // echo it
}
```

`nb::Result` means "would block" is a normal, typed outcome rather than an error code. `block!` loops until the operation completes.

## 16.3 Interrupt-Driven Receive with a Queue

Blocking `read` loses bytes if you are busy elsewhere. Receive in the ISR and push into a lock-free queue:

```rust ISR producer, main consumer
use heapless::spsc::{Consumer, Producer, Queue};
use stm32f4xx_hal::{serial::{Event, Rx}, pac::{self, interrupt, USART2}};

static mut QUEUE: Queue<u8, 128> = Queue::new();
static G_RX: Mutex<RefCell<Option<Rx<USART2>>>> = Mutex::new(RefCell::new(None));
static G_PROD: Mutex<RefCell<Option<Producer<'static, u8, 128>>>> = Mutex::new(RefCell::new(None));

// in main, before enabling the interrupt
let (prod, mut cons) = unsafe { (&mut *core::ptr::addr_of_mut!(QUEUE)).split() };   // the only unsafe: split the static queue once
rx.listen();                                         // enable RXNE interrupt
critical_section::with(|cs| {
    G_RX.borrow(cs).replace(Some(rx));
    G_PROD.borrow(cs).replace(Some(prod));
});
unsafe { cortex_m::peripheral::NVIC::unmask(pac::Interrupt::USART2); }

#[interrupt]
fn USART2() {
    critical_section::with(|cs| {
        if let (Some(rx), Some(prod)) = (
            G_RX.borrow(cs).borrow_mut().as_mut(),
            G_PROD.borrow(cs).borrow_mut().as_mut(),
        ) {
            while let Ok(b) = rx.read() {
                let _ = prod.enqueue(b);       // if full, drop the byte (count it in real code)
            }
        }
    });
}

// main loop
while let Some(b) = cons.dequeue() { /* feed the command parser */ }
```

The `unsafe` is confined to **one** line at start-up where the `static` queue is split into its two halves; afterwards the types guarantee a single producer and a single consumer.

## 16.4 A Command Parser

```rust Line editor with heapless::String
use heapless::String;

struct LineBuf { buf: String<64> }

impl LineBuf {
    fn push(&mut self, b: u8) -> Option<&str> {
        match b {
            b'\r' | b'\n' => {
                if self.buf.is_empty() { return None; }
                Some(self.buf.as_str())
            }
            b if b.is_ascii() && self.buf.push(b as char).is_ok() => None,
            _ => { self.buf.clear(); None }          // overflow or non-ASCII: discard the line
        }
    }
}

fn parse(line: &str) -> Option<Command> {
    let mut it = line.split_whitespace();
    match (it.next()?, it.next()) {
        ("led", Some("on")) => Some(Command::LedOn),
        ("led", Some("off")) => Some(Command::LedOff),
        ("adc", Some(ch)) => ch.parse().ok().map(Command::ReadAdc),
        _ => None,
    }
}
```

`&str` slicing means no copies; `parse::<u8>()` returns a `Result`, so a malformed number cannot crash the parser. Compare this with `strtok` and `atoi` in C.

## 16.5 `defmt` vs UART Logging

| | UART (`write!`) | `defmt` over RTT |
|---|---|---|
| Needs a terminal on the PC | Yes (VCP) | `probe-rs` shows it |
| Flash cost | Format strings in flash | Tiny - strings stay on PC |
| Time cost | Slow (baud rate) | Fast (memory buffer) |
| Visible without debugger | Yes | No - needs the probe |
| Use for | User console, field diagnostics | Development logging |
