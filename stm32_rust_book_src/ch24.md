## 24.1 What Makes a Driver Reusable

A reusable driver does not know about your board, your pins or your RTOS. It expresses **what the device does** using the `embedded-hal` traits and exposes a small typed API.

| Principle | In practice |
|---|---|
| Generic over the bus | `struct Dev<I2C>` where `I2C: I2c` |
| No globals | State lives inside the struct |
| Typed errors | `Result<T, Error<BusError>>` |
| No `unsafe` | `#![forbid(unsafe_code)]` |
| `no_std` | `#![no_std]`, optional `std` feature |
| Testable | Mock bus tests, pure conversion functions |

## 24.2 Skeleton of a Driver Crate

```rust lib.rs
#![no_std]
#![forbid(unsafe_code)]

use embedded_hal::i2c::I2c;

pub const DEFAULT_ADDR: u8 = 0x48;

#[derive(Debug, PartialEq)]
pub enum Error<E> { Bus(E), InvalidData }

pub struct Tmp102<I2C> { i2c: I2C, addr: u8 }

impl<I2C: I2c> Tmp102<I2C> {
    pub fn new(i2c: I2C) -> Self { Self { i2c, addr: DEFAULT_ADDR } }
    pub fn with_address(mut self, addr: u8) -> Self { self.addr = addr; self }

    pub fn read_temperature_dc(&mut self) -> Result<i16, Error<I2C::Error>> {
        let mut b = [0u8; 2];
        self.i2c.write_read(self.addr, &[0x00], &mut b).map_err(Error::Bus)?;
        Ok(raw_to_dc(b))
    }

    pub fn release(self) -> I2C { self.i2c }
}

fn raw_to_dc(b: [u8; 2]) -> i16 {
    let raw = ((b[0] as i16) << 4) | ((b[1] as i16) >> 4);   // 12-bit signed
    let raw = if raw & 0x800 != 0 { raw - 0x1000 } else { raw };
    (raw as i32 * 625 / 1000) as i16                         // 0.0625 C per count, result in 0.1 C
}
```

The builder-style `with_address` keeps constructors short while allowing alternate addresses.

## 24.3 Type-State Configuration

Use types to encode which mode a device is in, so illegal sequences do not compile:

```rust Type-state for a sensor mode
use core::marker::PhantomData;

pub struct Sleep;
pub struct Active;

pub struct Sensor<I2C, MODE> { i2c: I2C, _m: PhantomData<MODE> }

impl<I2C: I2c> Sensor<I2C, Sleep> {
    pub fn wake(mut self) -> Result<Sensor<I2C, Active>, Error<I2C::Error>> { /* write config */ todo!() }
}

impl<I2C: I2c> Sensor<I2C, Active> {
    pub fn read(&mut self) -> Result<i16, Error<I2C::Error>> { todo!() }
    pub fn sleep(self) -> Result<Sensor<I2C, Sleep>, Error<I2C::Error>> { todo!() }
}
```

Calling `read()` on a sleeping sensor is a **compile error** - the same technique `stm32f4xx-hal` uses for pin modes.

## 24.4 Async Variants

`embedded-hal-async` provides the same traits with `async fn`. A driver written against `embedded_hal_async::i2c::I2c` works with Embassy and awaits instead of blocking. Keep blocking and async drivers in one crate behind a feature flag or use a macro such as `maybe-async`.

## 24.5 Documentation and Publishing

- Document every public item with a `///` comment and an example.
- Specify the minimum supported Rust version and `embedded-hal` version in the README.
- Add a `CHANGELOG.md` and use semantic versioning.
- Publish with `cargo publish` after `cargo package --list` shows only what you intend.

## 24.6 Review Checklist

1. Does it compile with `--no-default-features` for the target?
2. Are all bus errors passed up unchanged?
3. Is every register address a named constant?
4. Is there any `unwrap()` outside tests?
5. Are the pure conversions tested?
