## 20.1 CAN on STM32

CAN is a differential multi-drop bus used in vehicles and industrial machines. A frame carries an **ID** (priority and meaning), a length and up to 8 data bytes. The STM32F446 has an **bxCAN** controller (CAN1, CAN2, CAN3 on this part) but the Nucleo has **no transceiver** - you need an external chip such as TJA1050, SN65HVD230 or MCP2551.

> [hw] Wiring | CAN1: PA11 = RX, PA12 = TX (AF9). Connect to the transceiver, then CANH and CANL with **120 Ohm termination at both ends** of the bus. Without termination, frames are corrupted.

> [warn] HAL support varies | `stm32f4xx-hal` does not ship a complete CAN driver. The common approach is the `bxcan` crate on top of the PAC, or `embassy-stm32` which has built-in CAN. Always check the crate version you use; the API below shows the concepts, not a fixed contract.

## 20.2 Bit Timing

CAN needs every node to agree on bit timing. At APB1 = 42 MHz the time quantum is `(prescaler)/42 MHz`.

| Setting | Value |
|---|---|
| Bit rate | 500 kbit/s |
| Prescaler | 6 (time quantum = 142.8 ns) |
| Quanta per bit | 1 sync + 11 BS1 + 2 BS2 = 14 |
| Sample point | 12/14 = 85.7 % |
| BTR register | 0x001A0005 |

Check: 42 MHz / 6 / 14 = 500 kHz.

## 20.3 Initialising with `bxcan`

```rust CAN1 at 500 kbit/s
use bxcan::{filter::Mask32, Fifo, Frame, StandardId, Data};

let mut can = bxcan::Can::builder(can1_peripheral)       // wraps pac::CAN1 via a small adapter
    .set_bit_timing(0x001A0005)
    .set_automatic_retransmit(true)
    .enable();

let mut filters = can.modify_filters();
filters.enable_bank(0, Fifo::Fifo0, Mask32::accept_all());
drop(filters);

nb::block!(can.enable_non_blocking()).unwrap();          // join the bus: wait for 11 recessive bits
```

## 20.4 Sending and Receiving

```rust Typed frames
let id = StandardId::new(0x321).unwrap();               // None if above 0x7FF
let data = Data::new(&[0x01, 0x02, 0x03, 0x04]).unwrap();   // None if more than 8 bytes
let frame = Frame::new_data(id, data);
can.transmit(&frame).ok();

if let Ok(rx) = can.receive() {
    if let bxcan::Id::Standard(id) = rx.id() {
        match id.as_raw() {
            0x321 => { /* handle */ }
            _ => {}
        }
    }
}
```

An ID above 0x7FF or a payload above 8 bytes cannot be constructed. Compare with the C pattern of writing past `Data[8]`.

## 20.5 Designing Messages with Types

Define the bus protocol once and encode and decode in one place:

```rust Message enum with explicit encoding
pub enum Msg { Telemetry { temp_dc: i16, fan_pct: u8 }, FanSet(u8) }

impl Msg {
    pub fn encode(&self) -> (u16, [u8; 8], usize) {
        match *self {
            Msg::Telemetry { temp_dc, fan_pct } => {
                let t = temp_dc.to_le_bytes();
                (0x100, [t[0], t[1], fan_pct, 0, 0, 0, 0, 0], 3)
            }
            Msg::FanSet(p) => (0x200, [p, 0, 0, 0, 0, 0, 0, 0], 1),
        }
    }
    pub fn decode(id: u16, d: &[u8]) -> Option<Msg> {
        match (id, d) {
            (0x100, [a, b, c, ..]) => Some(Msg::Telemetry { temp_dc: i16::from_le_bytes([*a, *b]), fan_pct: *c }),
            (0x200, [p, ..]) if *p <= 100 => Some(Msg::FanSet(*p)),
            _ => None,
        }
    }
}
```

Slice patterns reject short frames automatically. Host-test `decode(encode(x)) == x` for every variant.

## 20.6 Diagnostics

| Symptom | Cause |
|---|---|
| Never leaves init mode | No other node and no termination, or wrong bit timing |
| Bus-off | TX errors, usually missing termination or wrong baud rate |
| Frames lost | Filter rejects the ID, or FIFO overflow because main is too slow |
| Works on bench, fails in vehicle | Ground offset, no common-mode choke |

Use **loopback mode** first to test software without a transceiver, then **silent mode** to listen on a live bus without disturbing it.
