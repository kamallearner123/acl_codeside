## 15.1 Timers: Time Bases and PWM

Timer maths is hardware maths - the same as in Book 1 - but the HAL does the PSC/ARR calculation for you if you ask for a frequency.

```text Timer formula
f_update = f_timer / ((PSC + 1) * (ARR + 1))
```

On the F446 with APB1 at 42 MHz, a timer on APB1 receives **84 MHz** (the timer clock is doubled when the APB prescaler is not 1). Use the numbers from `clocks` instead of guessing.

```rust Periodic interrupt at 1 Hz
use stm32f4xx_hal::{timer::{Event, CounterHz}, pac::{self, interrupt}};

static G_TIMER: Mutex<RefCell<Option<CounterHz<pac::TIM3>>>> = Mutex::new(RefCell::new(None));

// in main
let mut timer = dp.TIM3.counter_hz(&clocks);
timer.start(1.Hz()).unwrap();            // the HAL computes PSC and ARR
timer.listen(Event::Update);
critical_section::with(|cs| G_TIMER.borrow(cs).replace(Some(timer)));
unsafe { cortex_m::peripheral::NVIC::unmask(pac::Interrupt::TIM3); }

#[interrupt]
fn TIM3() {
    critical_section::with(|cs| {
        if let Some(t) = G_TIMER.borrow(cs).borrow_mut().as_mut() {
            t.clear_flags(Event::Update);
        }
    });
    TICK.store(true, Ordering::Release);
}
```

## 15.2 PWM Output

```rust 1 kHz PWM on PA0 (TIM2_CH1)
use stm32f4xx_hal::{prelude::*, timer::Channel1};

let gpioa = dp.GPIOA.split();
let mut pwm = dp.TIM2.pwm_hz(Channel1::new(gpioa.pa0), 1.kHz(), &clocks).split();

let max = pwm.get_max_duty();
pwm.set_duty(max / 4);          // 25 %
pwm.enable();

loop {
    for step in 0..=100u32 {
        pwm.set_duty((max as u32 * step / 100) as u16);   // widen first to avoid overflow
        delay.delay_ms(10u32);
    }
}
```

> [tip] API names move | `pwm_hz`, `Channel1::new` and `split` match `stm32f4xx-hal` 0.21. Newer versions rename some of these; the concepts - pick pin, pick timer, pick frequency, set duty - do not change. Always compare with the `examples/` folder of your chosen version.

## 15.3 Safe Duty-Cycle Handling

A duty value outside 0..=max is a classic bug. Encode the constraint in a type:

```rust A validated percentage
#[derive(Clone, Copy)]
struct Percent(u8);

impl Percent {
    fn new(p: u8) -> Option<Self> { if p <= 100 { Some(Percent(p)) } else { None } }
    fn saturating(p: u8) -> Self { Percent(p.min(100)) }
    fn to_duty(self, max: u16) -> u16 { ((max as u32 * self.0 as u32) / 100) as u16 }
}
```

Every function that accepts a `Percent` can drop its own range check: the invalid state cannot exist.

## 15.4 Servo and Motor Control

| Device | PWM frequency | Duty meaning |
|---|---|---|
| SG90 servo | 50 Hz | 1.0 ms = 0 degrees, 2.0 ms = 180 degrees |
| DC motor via H-bridge | 10-20 kHz | Average motor voltage |
| LED brightness | 500 Hz - 1 kHz | Perceived brightness |
| Buzzer | 2-4 kHz | 50 % duty, frequency = pitch |

```rust Servo angle to duty
fn servo_duty(angle_deg: u16, max: u16) -> u16 {
    let angle = angle_deg.min(180) as u32;
    let pulse_us = 1000 + angle * 1000 / 180;          // 1000..2000 us
    ((max as u32 * pulse_us) / 20_000) as u16          // 20 ms period at 50 Hz
}
```

## 15.5 Input Capture and Encoders

Timers can also **measure**: input capture timestamps an edge (frequency of a tachometer), and encoder mode counts quadrature pulses in hardware. The HAL exposes `Qei` for encoders and the PAC for capture. Unit-test the conversion maths (counts to RPM) on the host.

## 15.6 Delays Are Not Timers

`delay.delay_ms()` blocks the CPU. For several activities at once, count ticks:

```rust Non-blocking timing with wrapping_sub
let now = TICKS.load(Ordering::Relaxed);
if now.wrapping_sub(last_blink) >= 500 { led.toggle(); last_blink = now; }
```

`wrapping_sub` makes the comparison immune to counter roll-over (chapter 2).
