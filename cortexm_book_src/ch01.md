## 1.1 What an Embedded Processor Is

An embedded processor runs one dedicated job inside a product: a motor controller, a thermostat, a car door module. Unlike a PC it has fixed software, tight cost and power limits, and usually real-time deadlines.

| Class | Example | Typical use |
|---|---|---|
| Microcontroller (MCU) | STM32, nRF52, RP2040 | CPU, flash, SRAM and peripherals on one chip |
| Application processor | Cortex-A SoC | Linux, external DRAM, MMU |
| DSP / accelerator | Cortex-M with DSP, NPU | Signal and ML workloads |

## 1.2 The Von Neumann and Harvard Models

A **Von Neumann** machine uses one bus for code and data. A **Harvard** machine has separate instruction and data paths so both can be fetched in the same cycle. Cortex-M uses a **modified Harvard** design: separate I-Code and D-Code buses to flash, plus a system bus, but a single unified 4 GB address space.

## 1.3 CPU, Memory and Peripherals

```text A minimal microcontroller
          +------+      +-------+      +--------+
  CPU --->| Bus  |----->| Flash |      | GPIO   |
          |matrix|----->| SRAM  |      | UART   |
          |      |----->| Periph|----->| Timer  |
          +------+      +-------+      +--------+
```

The CPU executes instructions fetched from memory. Peripherals appear **as memory addresses**; writing to an address can toggle a pin. This single idea is the key to everything in this book.

## 1.4 The Fetch-Decode-Execute Cycle

1. **Fetch** the instruction at the address in the program counter.
2. **Decode** it to find the operation and operands.
3. **Execute** it, then update registers, memory or flags.
4. Advance the PC and repeat.

Cortex-M overlaps these stages in a pipeline (3 stages on M0/M3/M4, deeper on M7), so throughput approaches one instruction per cycle.

## 1.5 Key Metrics

| Metric | Meaning |
|---|---|
| Clock frequency | Cycles per second (e.g. 180 MHz) |
| CPI / DMIPS per MHz | Work per cycle; Cortex-M4 is about 1.25 DMIPS/MHz |
| Interrupt latency | Cycles from event to first ISR instruction (12 on M3/M4) |
| Power | Active and sleep current, important for batteries |
| Determinism | Whether execution time is predictable |

> [tip] Determinism beats raw speed | A 100 MHz core with fixed 12-cycle interrupt entry is easier to certify than a faster core with caches and variable latency.
