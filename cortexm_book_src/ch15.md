## 15.1 Peripherals Are Addresses

On Cortex-M a peripheral register is just a location in memory. A store writes the hardware, a load reads it. The compiler must be told that these accesses have side effects.

## 15.2 The `volatile` Qualifier

```c Direct register access
#define GPIOA_BASE   0x40020000UL
#define GPIOA_MODER  (*(volatile uint32_t *)(GPIOA_BASE + 0x00))
#define GPIOA_ODR    (*(volatile uint32_t *)(GPIOA_BASE + 0x14))

GPIOA_MODER |= (1u << (5 * 2));      /* PA5 as output */
GPIOA_ODR   ^= (1u << 5);            /* toggle PA5 */
```

`volatile` forbids the compiler from caching, merging or removing the access. Without it a polling loop on a status flag may be optimised into an infinite loop.

## 15.3 Struct Overlays (CMSIS Style)

```c One struct per peripheral
typedef struct {
    volatile uint32_t MODER;
    volatile uint32_t OTYPER;
    volatile uint32_t OSPEEDR;
    volatile uint32_t PUPDR;
    volatile uint32_t IDR;
    volatile uint32_t ODR;
    volatile uint32_t BSRR;
} GPIO_TypeDef;

#define GPIOA ((GPIO_TypeDef *)0x40020000UL)
GPIOA->BSRR = (1u << 5);             /* set PA5 atomically */
```

The struct member offsets must match the reference manual exactly.

## 15.4 Read-Modify-Write Hazards

`ODR |= bit` is read, OR, write. An interrupt that changes `ODR` in between is overwritten. Vendors provide **set/reset registers** (`BSRR`) so a single write changes only the chosen pins.

## 15.5 Register Access Types

| Type | Meaning |
|---|---|
| rw | Read and write normally |
| r | Read only |
| w | Write only, reads undefined |
| rc_w1 | Read, clear by writing 1 |
| rc_r | Cleared by reading (status flags) |

> [warn] Clearing flags | Writing the whole register back can clear flags you did not intend. Write only the bit you mean.

## 15.6 Memory Barriers and Write Buffers

A store to a peripheral may sit in a write buffer. After changing a clock enable or interrupt setting, `DSB` ensures it completed before the next step.

```c Clock enable then use
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;
(void)RCC->AHB1ENR;                 /* dummy read ensures the write finished */
GPIOA->MODER |= ...;
```
