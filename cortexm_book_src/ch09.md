## 9.1 Why Thumb Exists

The classic ARM instruction set uses 32-bit instructions. **Thumb** introduced 16-bit encodings for better code density. **Thumb-2** mixes 16-bit and 32-bit instructions in one stream with no mode switch, giving ARM-like performance with Thumb-like size.

## 9.2 16-bit and 32-bit Encodings

The first halfword tells the decoder the length. If bits [15:11] are `11101`, `11110` or `11111` it is a 32-bit instruction; otherwise 16-bit.

| Form | Size | Notes |
|---|---|---|
| Narrow (16-bit) | 2 bytes | Mostly low registers R0-R7, often set flags |
| Wide (32-bit) | 4 bytes | All registers, larger immediates, more options |

```asm Assembler width control
    ADDS R0, R0, #1         @ narrow, 2 bytes
    ADD.W R0, R0, #1        @ force wide, 4 bytes, no flag update
```

## 9.3 IT Blocks

Thumb-2 has an **If-Then** instruction that makes up to four following instructions conditional, avoiding a branch.

```asm Conditional execution
    CMP  R0, #0
    ITE  EQ
    MOVEQ R1, #1
    MOVNE R1, #2
```

Not available on Armv6-M (M0/M0+).

## 9.4 Other Thumb-2 Features

- `CBZ` and `CBNZ`: compare and branch on zero in one instruction.
- `MOVW` and `MOVT`: load a 32-bit constant in two instructions.
- `BFI`, `BFC`, `UBFX`, `SBFX`: bit-field insert, clear, extract.
- `TBB` and `TBH`: table branch for switch statements.
- `UDIV` and `SDIV`: hardware divide.

## 9.5 Code Density

Typical code for the same C program is about 30 percent smaller than classic 32-bit ARM, which matters because flash costs silicon area.

## 9.6 Armv7E-M and Armv8-M Additions

DSP instructions (`SMLAD`, `QADD`), floating-point instructions (`VADD.F32`, `VMLA`), and in Armv8-M, TrustZone instructions (`SG`, `BXNS`) and the LOB loop extension on newer cores.
