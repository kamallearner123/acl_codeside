## 28.1 DMA in One Sentence

A Direct Memory Access controller copies data between memory and peripherals **without CPU involvement**. It is a bus master like the CPU, so it competes for the same buses and RAM.

DMA is **not part of the Cortex-M core**; it is a vendor peripheral, but its behaviour matters to every architect.

## 28.2 The Bus Matrix

```text STM32F4 simplified
Masters: Cortex-M4 (I, D, S), DMA1, DMA2, Ethernet, USB
Slaves : Flash, SRAM1/2, AHB1 periph, APB1 and APB2 via bridges
Each slave is arbitrated round-robin between masters.
```

When CPU and DMA access different slaves at the same moment, both proceed in parallel.

## 28.3 Transfer Types

| Type | Example |
|---|---|
| Memory to peripheral | UART transmit buffer |
| Peripheral to memory | ADC samples, UART receive |
| Memory to memory | Fast buffer copy |
| Circular mode | Continuous ADC or audio stream |
| Double buffer | Process one half while DMA fills the other |

## 28.4 Configuration Checklist

```c DMA setup order
DMA1_Stream5->CR  = 0;                         /* disable stream first */
while (DMA1_Stream5->CR & DMA_SxCR_EN) { }
DMA1_Stream5->PAR  = (uint32_t)&USART2->DR;    /* peripheral address */
DMA1_Stream5->M0AR = (uint32_t)rx_buf;         /* memory address */
DMA1_Stream5->NDTR = sizeof rx_buf;            /* count */
DMA1_Stream5->CR   = (4u << 25)                /* channel select */
                   | DMA_SxCR_MINC             /* increment memory */
                   | DMA_SxCR_CIRC             /* circular */
                   | DMA_SxCR_TCIE;            /* transfer complete interrupt */
USART2->CR3 |= USART_CR3_DMAR;                 /* UART issues DMA requests */
DMA1_Stream5->CR |= DMA_SxCR_EN;
```

The channel-to-peripheral mapping is fixed by silicon; read the DMA request table in the reference manual.

## 28.5 Pitfalls

| Pitfall | Cure |
|---|---|
| Buffer in unreachable RAM (CCM, TCM) | Place in main SRAM |
| Stack buffer that goes out of scope | Use static buffers |
| Cache coherency on M7 | Clean or invalidate or use non-cacheable region |
| Reading a buffer mid-transfer | Use half and complete callbacks |
| Alignment and data size mismatch | Match PSIZE and MSIZE to the peripheral |
| Forgetting to clear flags | Clear TCIF and HTIF in the ISR |

## 28.6 Impact on Architecture

DMA moves CPU load into **bus load**. High DMA traffic can slow CPU memory access. Use separate RAM blocks, use burst modes, and prefer circular buffers with half-complete events for streaming.
