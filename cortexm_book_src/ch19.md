## 19.1 What SysTick Is

SysTick is a 24-bit down-counting timer built into every Cortex-M core (optional on M0). It gives an RTOS or application a **periodic tick** that is portable across all vendors.

## 19.2 Registers (Base 0xE000E010)

| Register | Purpose |
|---|---|
| CTRL | Enable, interrupt enable, clock source, COUNTFLAG |
| LOAD | Reload value (24 bits) |
| VAL | Current value, writing clears it |
| CALIB | Calibration info |

## 19.3 Computing the Reload Value

```text Period maths
tick period = (LOAD + 1) / f_clock
LOAD = f_clock / f_tick - 1
Example: 168 MHz core, 1 kHz tick -> LOAD = 168000 - 1 = 167999
Maximum period at 168 MHz = 2^24 / 168 MHz = about 99.9 ms
```

## 19.4 Configuring It

```c CMSIS helper
SysTick_Config(SystemCoreClock / 1000);   /* 1 ms tick, interrupt on */

volatile uint32_t ms_ticks;
void SysTick_Handler(void) { ms_ticks++; }

void delay_ms(uint32_t ms) {
    uint32_t start = ms_ticks;
    while ((ms_ticks - start) < ms) { }
}
```

`SysTick_Config` loads the value, sets the SysTick priority to the lowest, clears the counter and enables the interrupt.

## 19.5 Uses

- Time base for `HAL_Delay`, `HAL_GetTick`, timeouts and software timers.
- Tick source for FreeRTOS and Zephyr.
- Polling schedulers (run tasks every N ticks).

## 19.6 Cautions

> [warn] Priority | An RTOS runs SysTick at the lowest priority. If a higher priority ISR runs long, ticks are late but the count is preserved only if SysTick is not missed twice. Keep ISRs short.

> [tip] Low power | Stop SysTick in deep sleep and use the RTC or LPTIM for the tick (tickless idle).

The cycle counter in the DWT unit is a better tool for measuring short durations of a few cycles.
