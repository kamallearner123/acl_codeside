## 35.1 The Complete Timeline

This chapter ties together the whole book: from the instant power is applied until the first line of `main()` runs.

```text Power-on to main
1. Power rail rises; power-on reset releases when the supply is stable.
2. Internal RC oscillator (HSI) starts; CPU clock = 16 MHz.
3. Boot pins sampled; flash aliased at 0x00000000.
4. Core reads word 0: initial MSP.
5. Core reads word 1: Reset vector.
6. Core jumps to Reset_Handler.
7. SystemInit: FPU enable, reset clock registers, set VTOR.
8. Copy .data from flash to SRAM.
9. Zero .bss.
10. Initialise C library (__libc_init_array, static constructors).
11. Call main().
12. main: HAL_Init, clock configuration, peripheral init, application loop.
```

## 35.2 What Is Guaranteed at Entry to main

- `.data` globals have their initial values; `.bss` is zero.
- MSP points to the top of RAM; the CPU is privileged in thread mode.
- Interrupts are enabled but none is configured, except possibly SysTick after `HAL_Init`.
- Clock is still the default (HSI) until your code reconfigures it.

## 35.3 Order of Initialisation in main

```c A robust order
int main(void) {
    HAL_Init();                    /* flash prefetch, SysTick, NVIC grouping */
    SystemClock_Config();          /* raise clocks */
    MX_GPIO_Init();                /* clock, pins */
    MX_DMA_Init();                 /* DMA before the peripheral that uses it */
    MX_USART2_UART_Init();
    for (;;) { app_step(); }
}
```

## 35.4 Debugging Boot Problems

| Symptom | Check |
|---|---|
| Never reaches main | Initial SP or reset vector wrong, bad linker script |
| Stuck in SystemInit | Crystal not starting; check timeout code |
| Globals wrong at start | `.data` copy range or LMA wrong |
| Works under debugger only | VTOR or clock state differs after power-on |
| Boots, then HardFault | Stack too small, FPU not enabled, clocks out of limit |

## 35.5 Time Budget

Typical boot: reset to main in under 100 microseconds at 16 MHz, plus crystal start-up of 1-10 ms and clock configuration. Bootloaders add integrity checks and a handover (set VTOR, MSP, jump).

## 35.6 Putting It All Together

Reset (22) reads the vector table (23); the linker script (24) decided where data lives; startup copies and zeroes memory (12); clocks (25) and flash latency (11) are tuned; peripherals (34) are set up; the NVIC (16) and SysTick (19) bring the system to life; the debug unit (30-32) lets you see it all.
