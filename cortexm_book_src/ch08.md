## 8.1 What an Instruction Set Is

The instruction set architecture (ISA) defines every operation the CPU can perform and how it is encoded. Compilers generate it; you read it when debugging.

## 8.2 Instruction Categories

| Category | Examples |
|---|---|
| Data processing | `ADD`, `SUB`, `AND`, `ORR`, `EOR`, `LSL`, `MOV`, `CMP` |
| Load and store | `LDR`, `STR`, `LDRB`, `STRH`, `LDM`, `STM`, `PUSH`, `POP` |
| Branch | `B`, `BL`, `BX`, `BLX`, `CBZ`, `CBNZ` |
| Multiply and divide | `MUL`, `MLA`, `SDIV`, `UDIV` |
| System | `MRS`, `MSR`, `SVC`, `WFI`, `WFE`, `DMB`, `DSB`, `ISB`, `BKPT` |

## 8.3 Load-Store Architecture

Arithmetic works only on registers. To change a variable in memory you load it, operate, and store it back.

```asm counter++ in assembly
    LDR  R1, =counter
    LDR  R0, [R1]
    ADDS R0, R0, #1
    STR  R0, [R1]
```

This is why `counter++` is **not atomic**: an interrupt between the load and the store can lose an update.

## 8.4 Addressing Modes

```asm The common forms
    LDR R0, [R1]            @ base register
    LDR R0, [R1, #8]        @ base plus immediate offset
    LDR R0, [R1, R2]        @ base plus register
    LDR R0, [R1, #4]!       @ pre-indexed, R1 updated
    LDR R0, [R1], #4        @ post-indexed, R1 updated after
    LDR R0, =0x40020000     @ literal pool constant
```

## 8.5 Condition Flags and Branches

Instructions with the `S` suffix update flags. A conditional branch tests them:

```asm A loop
    MOVS R0, #10
loop:
    SUBS R0, R0, #1         @ updates Z
    BNE  loop               @ branch if not equal (Z=0)
```

| Suffix | Condition |
|---|---|
| EQ / NE | Equal, not equal |
| CS / CC | Carry set, clear (unsigned higher or same, lower) |
| MI / PL | Negative, positive |
| GE / LT | Signed greater or equal, less than |
| HI / LS | Unsigned higher, lower or same |

## 8.6 Useful System Instructions

- `WFI` waits for an interrupt (sleep). `WFE` waits for an event.
- `DSB` ensures prior memory accesses completed. `ISB` flushes the pipeline.
- `BKPT #0` triggers a debug breakpoint.
