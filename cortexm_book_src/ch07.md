## 7.1 General-Purpose Registers R0-R12

Thirteen 32-bit registers for data and addresses. The ARM procedure call standard (AAPCS) assigns roles:

| Registers | AAPCS role |
|---|---|
| R0-R3 | Arguments and return value, caller-saved scratch |
| R4-R11 | Callee-saved: a function must preserve them |
| R12 (IP) | Intra-procedure scratch |

```c Where the arguments go
int add3(int a, int b, int c);   // a in R0, b in R1, c in R2, result in R0
```

Two 32-bit return values use R0 and R1; 64-bit values use R0:R1.

## 7.2 Stack Pointer R13

The SP points to the **last pushed** item (full descending stack). It is always word-aligned; AAPCS requires 8-byte alignment at public interfaces. Pushing decrements SP first.

```asm Push and pop
    PUSH {R4-R6, LR}     @ SP = SP - 16, store the four registers
    ...
    POP  {R4-R6, PC}     @ restore and return in one instruction
```

## 7.3 Link Register R14

`BL` (branch with link) stores the return address in LR. A leaf function can return with `BX LR`. A non-leaf function must save LR first because its own calls overwrite it.

In exceptions LR holds a special **EXC_RETURN** value (such as 0xFFFFFFF9) that tells the core how to return.

## 7.4 Program Counter R15

Reads as the address of the current instruction plus 4 (because of the pipeline). Writing to PC branches. Bit 0 is ignored on write but must be 1 in the value for a branch (Thumb).

## 7.5 xPSR

Three overlapping views of one register:

| View | Bits | Content |
|---|---|---|
| APSR | 31:27 | N, Z, C, V, Q flags (and GE on M4) |
| IPSR | 8:0 | Active exception number (0 = thread mode) |
| EPSR | 24, 26:25 and 15:10 | Thumb bit (T), IT state |

The **T bit must be 1**. If it is 0, the next instruction causes an INVSTATE UsageFault.

| Flag | Set when |
|---|---|
| N | Result is negative |
| Z | Result is zero |
| C | Carry out or no borrow |
| V | Signed overflow |

## 7.6 The Register File During a Call

```text Caller and callee
caller:  MOV R0, #5 ; MOV R1, #7 ; BL add      @ LR = return address
callee:  ADD R0, R0, R1 ; BX LR               @ result in R0
```
