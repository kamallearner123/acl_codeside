## 18.1 Exceptions vs Interrupts

An **exception** is any event that changes normal flow: reset, faults, system calls, timers and external interrupts. An **interrupt** is an exception caused by a peripheral. The core numbers them all.

## 18.2 The Exception Table

| No. | Exception | Priority | Notes |
|---|---|---|---|
| 1 | Reset | -3 (fixed) | Entry at reset |
| 2 | NMI | -2 (fixed) | Cannot be masked |
| 3 | HardFault | -1 (fixed) | Catch-all fault |
| 4 | MemManage | Configurable | MPU violation (M3+) |
| 5 | BusFault | Configurable | Bus error (M3+) |
| 6 | UsageFault | Configurable | Illegal instruction, divide by zero (M3+) |
| 11 | SVCall | Configurable | Supervisor call |
| 12 | DebugMonitor | Configurable | Debug event |
| 14 | PendSV | Configurable | Context switch |
| 15 | SysTick | Configurable | System timer |
| 16+ | IRQ0, IRQ1, ... | Configurable | Peripheral interrupts |

## 18.3 Exception Number vs IRQ Number

`IRQn = exception number - 16`. CMSIS uses negative IRQn for system exceptions (`SysTick_IRQn = -1`).

## 18.4 Exception States

- **Inactive**: not active or pending.
- **Pending**: waiting to be serviced.
- **Active**: currently running or preempted.
- **Active and pending**: running and requested again.

## 18.5 Priority Rules

Reset, NMI and HardFault have fixed negative priorities and are always above configurable exceptions. If two pending exceptions share a priority, the **lower exception number** goes first.

## 18.6 Returning from an Exception

The handler returns by loading `EXC_RETURN` into PC (`BX LR`). Its value selects the target:

| EXC_RETURN | Return to |
|---|---|
| 0xFFFFFFF1 | Handler mode, MSP |
| 0xFFFFFFF9 | Thread mode, MSP |
| 0xFFFFFFFD | Thread mode, PSP |
| 0xFFFFFFE1 and others | Same, with FPU frame |

An RTOS context switch works by altering LR/PSP before returning so the "return" resumes another task.

## 18.7 Exception Entry and the Vector Table

On entry the core reads the handler address from `VTOR + 4 * exception_number`, which is the subject of chapter 23.
