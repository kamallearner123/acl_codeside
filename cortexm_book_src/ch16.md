## 16.1 The Nested Vectored Interrupt Controller

The NVIC is part of the core and handles **external interrupts** (IRQs) from peripherals. It provides enable and disable, pending state, priority and nesting, with a fixed low latency of 12 cycles on M3 and M4.

| Feature | M0/M0+ | M3/M4/M7 |
|---|---|---|
| Max external IRQs | 32 | 240 |
| Priority levels | 4 | 8 to 256 (vendor chooses bits) |
| BASEPRI | No | Yes |
| Priority grouping | No | Yes |

## 16.2 Registers (Base 0xE000E100)

| Register | Purpose |
|---|---|
| ISER[n] | Set enable, write 1 to enable IRQ |
| ICER[n] | Clear enable |
| ISPR[n] | Set pending (software trigger) |
| ICPR[n] | Clear pending |
| IABR[n] | Active bit (read only) |
| IPR[n] | Priority, one byte per IRQ |
| STIR | Software trigger interrupt register |

## 16.3 Priorities

Lower number means higher priority. Vendors implement only the **top N bits** of each 8-bit priority field. STM32 implements 4 bits, so valid values are 0x00, 0x10, ..., 0xF0 and CMSIS shifts for you.

```c CMSIS NVIC functions
NVIC_SetPriority(USART2_IRQn, 5);
NVIC_EnableIRQ(USART2_IRQn);
NVIC_ClearPendingIRQ(EXTI0_IRQn);
```

## 16.4 Preemption and Sub-Priority

`SCB->AIRCR.PRIGROUP` splits the priority bits into **preempt priority** (can interrupt another handler) and **sub-priority** (only breaks ties among pending). With 4 bits and group 4, all 4 bits are preempt priority, giving 16 nesting levels, the usual choice with an RTOS.

## 16.5 Nesting and Tail-Chaining

- **Preemption**: a higher-priority interrupt interrupts a running ISR.
- **Tail-chaining**: if another interrupt is pending when one ends, the core skips unstacking and stacking and jumps directly (6 cycles).
- **Late arrival**: a higher-priority interrupt arriving during stacking takes over without a second stacking.

## 16.6 Masking

`PRIMASK` blocks everything configurable, `BASEPRI` blocks priorities at or below a value (so critical sections need not stop urgent ISRs).

```c BASEPRI critical section
__set_BASEPRI(5 << 4);       /* block priority 5 and lower urgency */
/* shared data work */
__set_BASEPRI(0);
```
