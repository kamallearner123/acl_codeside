## 25.1 Why Clocks Matter

Every synchronous circuit needs a clock. The clock tree decides CPU speed, peripheral speed, power and timing accuracy. Wrong clock setup is the most common cause of wrong baud rates, wrong timer periods and flash errors.

## 25.2 Clock Sources

| Source | Accuracy | Notes |
|---|---|---|
| Internal RC (HSI, 16 MHz) | About 1 percent | Starts instantly, default after reset |
| External crystal (HSE) | 10-50 ppm | Needed for USB, CAN, precise timing |
| PLL | Multiplier | Derives high frequencies from HSI or HSE |
| LSE 32.768 kHz | Very high | RTC |
| LSI 32 kHz | Low | Watchdog |

## 25.3 The PLL

```text STM32F446 PLL example: 8 MHz HSE to 180 MHz
VCO input  = HSE / PLLM       = 8 / 4   = 2 MHz
VCO output = VCO input * PLLN = 2 * 180 = 360 MHz
SYSCLK     = VCO output / PLLP = 360 / 2 = 180 MHz
USB / SDIO = VCO output / PLLQ = 360 / 7 (about 51 MHz, adjust to 48 MHz when needed)
```

Constraints: VCO input 1-2 MHz, VCO output 100-432 MHz.

## 25.4 Bus Prescalers

| Bus | Source | Max on F446 |
|---|---|---|
| SYSCLK | PLL | 180 MHz |
| AHB (HCLK) | SYSCLK / prescaler | 180 MHz |
| APB1 | HCLK / prescaler | 45 MHz |
| APB2 | HCLK / prescaler | 90 MHz |

When the APB prescaler is not 1, **timers on that bus run at twice the APB frequency**.

## 25.5 Start-Up Sequence

1. Enable HSE and wait for `HSERDY` (with a timeout).
2. Configure power regulator and flash latency for the target frequency.
3. Configure PLL and enable it; wait for `PLLRDY`.
4. Set bus prescalers.
5. Switch SYSCLK to the PLL and wait for the switch status.
6. Update `SystemCoreClock` and reconfigure SysTick.

> [warn] Fail-safe | If the crystal fails to start, the code must time out and fall back to HSI. The Clock Security System (CSS) can raise an NMI if HSE fails at run time.

## 25.6 Clock Gating and Power

Peripherals are off until their clock is enabled in the RCC (`RCC->AHB1ENR |= ...`). Disabling unused clocks saves power. Reading a peripheral whose clock is off often returns zero or causes a bus fault.
