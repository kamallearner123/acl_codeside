## 22.1 What Reset Does

Reset puts the core in a known state and starts execution from the vector table. Sources include power-on, external NRST pin, watchdog, software reset (`NVIC_SystemReset`), brown-out and low-power exit.

## 22.2 What the Core Does After Reset

1. Core registers are reset, mode is Thread, privileged, MSP selected.
2. The CPU reads the **initial MSP** from the first word of the vector table.
3. It reads the **reset vector** from the second word.
4. It jumps to the reset handler (with the Thumb bit set).

```text First words of flash
0x08000000: 0x20020000   <- initial stack pointer
0x08000004: 0x08000189   <- Reset_Handler address (+1 for Thumb)
```

## 22.3 Boot Selection on STM32

BOOT0 and BOOT1 pins or option bytes choose what is aliased to 0x00000000.

| BOOT0 | Boot from |
|---|---|
| 0 | Main flash at 0x08000000 |
| 1 with BOOT1 = 0 | System memory (ST bootloader) |
| 1 with BOOT1 = 1 | Embedded SRAM |

## 22.4 The Startup Code

The reset handler is the first code that runs. It prepares the C environment:

```asm Reset_Handler (GCC startup, simplified)
Reset_Handler:
    LDR   SP, =_estack         @ not needed on Cortex-M (hardware loaded it) but common
    BL    SystemInit           @ clocks, FPU enable, vector table offset
    LDR   R0, =_sdata          @ copy .data from flash to SRAM
    LDR   R1, =_edata
    LDR   R2, =_sidata
copy:
    CMP   R0, R1
    ITT   LT
    LDRLT R3, [R2], #4
    STRLT R3, [R0], #4
    BLT   copy
    LDR   R0, =_sbss           @ zero .bss
    LDR   R1, =_ebss
    MOVS  R2, #0
zero:
    CMP   R0, R1
    IT    LT
    STRLT R2, [R0], #4
    BLT   zero
    BL    __libc_init_array    @ C++ constructors and init arrays
    BL    main
hang:
    B     hang                 @ main must never return
```

## 22.5 Reset Cause Flags

The RCC records why the chip reset (power, pin, watchdog, software, brown-out). Read and clear them at startup to log the reason.

```c Reading the cause
if (RCC->CSR & RCC_CSR_IWDGRSTF) log("watchdog reset");
RCC->CSR |= RCC_CSR_RMVF;           /* clear flags */
```
