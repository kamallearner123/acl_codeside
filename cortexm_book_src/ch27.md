## 27.1 Floating Point on Cortex-M

Floating-point support is **optional**. Without an FPU the compiler calls software routines (`__aeabi_fadd`), costing about 20-100 cycles per operation. With an FPU most operations take 1-14 cycles.

| Core | FPU option |
|---|---|
| M0, M0+, M3 | None |
| M4 | FPv4-SP single precision |
| M7 | FPv5 single or double |
| M33 | FPv5-SP single |

## 27.2 FPU Registers

- 32 single-precision registers S0-S31 (also seen as 16 double D0-D15).
- `FPSCR`: status and control (rounding mode, flags, flush-to-zero, default NaN).

## 27.3 Enabling the FPU

The FPU is **off at reset**. Give coprocessors CP10 and CP11 full access before the first floating-point instruction, typically in `SystemInit`.

```c Enable CP10 and CP11
SCB->CPACR |= (3UL << 20) | (3UL << 22);
__DSB();
__ISB();
```

Using floating point before this causes a UsageFault (NOCP).

## 27.4 ABI Choices

| Flag | Meaning |
|---|---|
| `-mfloat-abi=soft` | All floating point in software |
| `-mfloat-abi=softfp` | Hardware FPU, but arguments passed in integer registers |
| `-mfloat-abi=hard` | Hardware FPU and arguments in S registers |

All linked objects and libraries must use the same ABI.

## 27.5 Cost on Context Switch and Interrupts

On exception entry, if the FPU was used, the core stacks S0-S15 and FPSCR in addition to the normal frame (26 words instead of 8). **Lazy stacking** reserves the space but only saves it if an ISR actually uses floating point, keeping latency low.

> [tip] Keep ISRs integer only | Avoid floating point in interrupt handlers; it forces the larger frame and extra cycles.

## 27.6 Precision Pitfalls

- A literal `1.0` is `double`; write `1.0f` or the compiler uses slow double maths even on an F-only FPU.
- `printf("%f")` pulls in a large library; use `-u _printf_float` consciously.
- Single precision has about 7 decimal digits; accumulate long sums carefully.

```c Avoid accidental doubles
float a = x * 0.5;      /* double multiply, convert back (slow on M4F) */
float b = x * 0.5f;     /* single-precision multiply (fast) */
```
