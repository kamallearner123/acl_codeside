## 34.1 The Core Is Only Part of the Chip

STM32 is an example **implementation** around a Cortex-M core. The core is identical across vendors; everything outside it is vendor design. Learning the pattern lets you read any vendor's reference manual.

```text STM32F4 system architecture
Cortex-M4 (I-Code, D-Code, System buses) --+
DMA1, DMA2, USB, Ethernet -----------------+--> Bus matrix --> Flash, SRAM, FSMC
                                                           --> AHB1 --> GPIO, DMA, RCC
                                                           --> APB bridges --> APB1: TIM2-7, USART2-5, I2C, SPI2/3, CAN
                                                                               APB2: TIM1/8, USART1/6, SPI1, ADC
```

## 34.2 Typical Peripheral Anatomy

Nearly every peripheral follows the same model:

| Register role | Typical name |
|---|---|
| Control | `CR1`, `CR2` (enable, mode, interrupt enable) |
| Status | `SR` / `ISR` (flags) |
| Data | `DR` / `TDR` / `RDR` |
| Configuration | `PSC`, `ARR`, `BRR`, `MODER` |
| Flag clear | `ICR` or write-0 / write-1 to `SR` |

```c Pattern for any peripheral
RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;   /* 1. enable clock */
/* 2. configure pins and alternate function */
TIM2->PSC = 83;                       /* 3. configure the peripheral */
TIM2->DIER |= TIM_DIER_UIE;           /* 4. enable its interrupt source */
NVIC_EnableIRQ(TIM2_IRQn);            /* 5. enable in the NVIC */
TIM2->CR1 |= TIM_CR1_CEN;             /* 6. start */
```

## 34.3 GPIO and Alternate Functions

Each pin has a mode register (input, output, alternate, analog), type, speed, pull and an **alternate-function mux** (AF0-AF15). The datasheet's alternate function table says which signals can appear on which pin.

## 34.4 Three Levels of Interrupt Path

An event takes three enable gates: peripheral flag enabled in the peripheral, interrupt enabled at the NVIC, and global masks open. All three must be right.

## 34.5 Mapping Other Vendors

| Concept | STM32 | NXP | Nordic nRF |
|---|---|---|---|
| Clock gate | RCC enable registers | SIM_SCGC | Always clocked, task/event model |
| Pin mux | GPIO AF | PORTx_PCR MUX | PSEL registers |
| Peripheral base | Fixed in memory map | Fixed | Fixed |
| DMA | DMAx streams | eDMA | EasyDMA in each peripheral |

The words differ; the pattern of **clock, pins, configure, interrupt, start** does not.

## 34.6 Reading a Reference Manual Efficiently

1. Block diagram and clock section.
2. Functional description for your mode.
3. Register map and bit fields.
4. Interrupt table and DMA request table.
5. Errata sheet for your silicon revision.
