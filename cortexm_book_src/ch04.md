## 4.1 Cortex-M0 and M0+

Armv6-M, a subset of Thumb-2. The M0+ has a 2-stage pipeline and optionally an MPU, a single-cycle I/O port and a vector table offset register. Lower power than M0.

- No hardware divide (software routine) and a 32-bit multiplier (1 or 32 cycles by option).
- Up to 32 external interrupts, 4 priority levels.
- No `CBZ`, `IT` blocks, and most 32-bit Thumb-2 instructions.

## 4.2 Cortex-M3

Armv7-M. Full Thumb-2, hardware divide (`SDIV`, `UDIV`), up to 240 interrupts, 8-256 priority levels, optional MPU and **bit-banding**, with 12-cycle interrupt latency.

## 4.3 Cortex-M4

Armv7E-M. Everything in M3 plus:

- DSP extensions: single-cycle 16x16 MAC, SIMD operations (`SMLAD`, `QADD16`), saturating arithmetic.
- Optional single-precision FPU (the "F" in M4F), FPv4-SP.

## 4.4 Cortex-M7

Armv7E-M, 6-stage dual-issue pipeline, optional I-cache and D-cache, **TCM** (tightly coupled memory) for deterministic access, optional double-precision FPU, AXI bus plus AHB peripheral port. Cores reach 400-1000 MHz.

## 4.5 Cortex-M23 and M33

Armv8-M adds **TrustZone** (secure and non-secure worlds), stack limit registers, and in Mainline the full M4 feature set. M33 is the common secure IoT choice.

## 4.6 Side-by-Side

| Feature | M0+ | M3 | M4 | M7 | M33 |
|---|---|---|---|---|---|
| Architecture | v6-M | v7-M | v7E-M | v7E-M | v8-M Main |
| HW divide | No | Yes | Yes | Yes | Yes |
| DSP | No | No | Yes | Yes | Yes |
| FPU | No | No | Optional SP | Optional SP/DP | Optional SP |
| MPU | Optional | Optional | Optional | Optional | Optional |
| Cache | No | No | No | Optional | Optional |
| TrustZone | No | No | No | No | Optional |

## 4.7 Selecting the Compiler Flags

```text GCC flags per core
Cortex-M0+  : -mcpu=cortex-m0plus -mthumb
Cortex-M3   : -mcpu=cortex-m3     -mthumb
Cortex-M4F  : -mcpu=cortex-m4     -mthumb -mfpu=fpv4-sp-d16 -mfloat-abi=hard
Cortex-M7   : -mcpu=cortex-m7     -mthumb -mfpu=fpv5-d16    -mfloat-abi=hard
Cortex-M33  : -mcpu=cortex-m33    -mthumb -mfpu=fpv5-sp-d16 -mfloat-abi=hard
```
