## 2.1 Who Is Arm?

Arm Ltd. designs processor **architectures and cores** and licenses them. Arm does not sell chips: STMicroelectronics, NXP, Nordic and others license a core, add flash, SRAM and peripherals, and manufacture a **microcontroller**. This is why one core knowledge applies across vendors.

## 2.2 Architecture vs Microarchitecture vs Chip

| Term | Meaning | Example |
|---|---|---|
| Architecture | The instruction set and programmer's view | Armv7-M |
| Microarchitecture (core) | A specific implementation | Cortex-M4 |
| SoC / MCU | Core plus vendor peripherals | STM32F446 |
| Board | MCU plus power, debug, connectors | NUCLEO-F446RE |

## 2.3 The Three Profiles

| Profile | Letter | Target | Example |
|---|---|---|---|
| Application | A | Rich OS, MMU, high performance | Cortex-A53 |
| Real-time | R | Hard real-time, safety | Cortex-R5 |
| Microcontroller | M | Low power, low cost, deterministic | Cortex-M4 |

This book covers the **M profile**.

## 2.4 Architecture Versions

| Architecture | Cores |
|---|---|
| Armv6-M | Cortex-M0, M0+, M1 |
| Armv7-M | Cortex-M3 |
| Armv7E-M | Cortex-M4, M7 (adds DSP, optional FPU) |
| Armv8-M Baseline | Cortex-M23 |
| Armv8-M Mainline | Cortex-M33, M55, M85 (adds TrustZone, optional) |

## 2.5 Licensing Model

Silicon vendors choose **implementation options** when they build a chip: number of interrupts, presence of MPU or FPU, number of breakpoints. Two Cortex-M4 chips can therefore differ. Always confirm in the vendor reference manual, not just the Arm core manual.

> [warn] Two documents | Arm documents the core (Technical Reference Manual, Generic User Guide). The chip vendor documents the integration (reference manual). You need both.
