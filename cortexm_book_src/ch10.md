## 10.1 One 4 GB Address Space

Cortex-M uses 32-bit addresses: 4 GB total. Arm defines a **fixed high-level map** so all vendors place things in the same broad regions.

| Range | Region | Contents |
|---|---|---|
| 0x00000000 - 0x1FFFFFFF | Code | Flash, boot alias, ROM |
| 0x20000000 - 0x3FFFFFFF | SRAM | On-chip RAM |
| 0x40000000 - 0x5FFFFFFF | Peripheral | APB and AHB peripherals |
| 0x60000000 - 0x9FFFFFFF | External RAM | FMC or FSMC memory |
| 0xA0000000 - 0xDFFFFFFF | External device | Memory-mapped devices |
| 0xE0000000 - 0xE00FFFFF | Private peripheral bus | NVIC, SysTick, SCB, debug |
| 0xE0100000 - 0xFFFFFFFF | Vendor-specific | Implementation defined |

## 10.2 A Real Example: STM32F446

| Address | What |
|---|---|
| 0x08000000 | Main flash (512 KB), aliased to 0x00000000 at boot |
| 0x1FFF0000 | System memory (ST bootloader) |
| 0x20000000 | SRAM1 and SRAM2 (128 KB) |
| 0x40000000 | APB1 peripherals |
| 0x40010000 | APB2 peripherals |
| 0x40020000 | AHB1 peripherals (GPIO, DMA) |
| 0xE000E000 | System Control Space |

## 10.3 Memory Types and Attributes

| Type | Behaviour |
|---|---|
| Normal | Reads and writes may be reordered, cached, merged |
| Device | No caching, no speculation, access order preserved per device |
| Strongly ordered | Strict order and completion |

Peripheral regions are Device or Strongly ordered; accesses are not merged or reordered, so each store reaches the hardware as you wrote it.

## 10.4 Execute Never and Region Rules

The peripheral and system regions are execute-never (XN). Running code from SRAM is allowed. This is how a RAM-based function or bootloader works.

## 10.5 Bit-Banding (M3 and M4)

Single bits in the first 1 MB of SRAM and peripheral regions have a word alias so a bit write is atomic.

```text Bit-band alias formula
alias = base_alias + (byte_offset * 32) + (bit_number * 4)
SRAM  : base 0x20000000, alias 0x22000000
Periph: base 0x40000000, alias 0x42000000
```

> [warn] Not portable | Bit-banding is absent on M0, M7 and Armv8-M. Prefer vendor set/reset registers (such as GPIO BSRR) or atomic instructions.
