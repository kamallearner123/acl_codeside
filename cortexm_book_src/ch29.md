## 29.1 Why Caches Exist

Flash and external memory are slower than a fast core. A **cache** keeps recently used instructions and data in small fast memory next to the CPU. Cortex-M0 to M4 have no cache in the core (vendors may add one, like ST's ART accelerator); **Cortex-M7 and M55 optionally include L1 I-cache and D-cache**.

## 29.2 Memory Hierarchy

| Level | Speed | Size |
|---|---|---|
| Registers | 0 cycles | 16 words |
| TCM | 1 cycle, deterministic | 16-512 KB |
| L1 cache | 1-2 cycles | 4-64 KB |
| On-chip SRAM | 1-4 cycles | 64 KB - 1 MB |
| Flash | Several wait states | 128 KB - 2 MB |
| External RAM | 10+ cycles | MB |

## 29.3 Tightly Coupled Memory

TCM (ITCM for code, DTCM for data) connects directly to the core with no cache and no wait states. Use it for **hard real-time** ISRs and interrupt vectors, DSP buffers and stacks.

## 29.4 Cache Coherency Problem

The D-cache can hold a copy different from main memory when DMA or another bus master writes behind the CPU's back.

| Scenario | Fix |
|---|---|
| DMA writes memory, CPU then reads | **Invalidate** the cache range before reading |
| CPU writes, DMA reads | **Clean** (write back) the range before starting DMA |
| Shared buffers | Place in a **non-cacheable** MPU region |

```c CMSIS cache maintenance (M7)
SCB_EnableICache();
SCB_EnableDCache();
SCB_CleanDCache_by_Addr((uint32_t *)tx_buf, len);        /* before DMA reads */
SCB_InvalidateDCache_by_Addr((uint32_t *)rx_buf, len);   /* after DMA writes */
```

Cache lines are 32 bytes; DMA buffers must be **aligned to and padded to 32 bytes**.

## 29.5 Write Policies

- **Write-through**: writes go to cache and memory; simple and safer.
- **Write-back**: writes stay in the cache until evicted; fast but needs cleaning for DMA.
- Policies are set with MPU region attributes (TEX, C, B, S).

## 29.6 Memory Barriers

Barriers enforce order when caches, write buffers and DMA are involved.

| Instruction | Ensures |
|---|---|
| `DMB` | Memory accesses before it are observed before those after |
| `DSB` | All earlier accesses have completed |
| `ISB` | Pipeline flushed, later instructions refetched |

> [warn] Heisenbugs | Cache bugs appear as data that is "almost right". Test with the cache on and off; if the bug disappears with it off, suspect coherency.
