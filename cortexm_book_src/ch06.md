## 6.1 Register Overview

A register is a small, very fast storage cell inside the CPU. There are two kinds you must keep apart:

| Kind | Where | Examples |
|---|---|---|
| **CPU core registers** | Inside the core, no address | R0-R12, SP, LR, PC, xPSR |
| **Peripheral registers** | In the memory map, with an address | GPIOA_ODR, USART2_DR |

## 6.2 Core Register Set

```text Register file
R0-R7    low registers   (accessible to all 16-bit instructions)
R8-R12   high registers  (limited use in 16-bit Thumb)
R13  SP  stack pointer   (MSP and PSP banked)
R14  LR  link register
R15  PC  program counter
xPSR     status register (APSR + IPSR + EPSR)
```

## 6.3 Special-Purpose Registers

Read and write only with `MRS` and `MSR`: `PRIMASK`, `FAULTMASK`, `BASEPRI`, `CONTROL`, plus the three views of xPSR.

```asm Reading special registers
    MRS  R0, PRIMASK
    MRS  R1, CONTROL
    MSR  BASEPRI, R2
    CPSID i             @ set PRIMASK, disable interrupts
    CPSIE i             @ clear PRIMASK, enable interrupts
```

## 6.4 Memory-Mapped Core Peripherals

Beyond the register file, the core has system registers in the System Control Space at `0xE000E000`: NVIC, SysTick, SCB, MPU, FPU control.

| Block | Base address |
|---|---|
| SysTick | 0xE000E010 |
| NVIC | 0xE000E100 |
| SCB | 0xE000ED00 |
| MPU | 0xE000ED90 |
| DWT | 0xE0001000 |

## 6.5 Register Naming in Documents

Reference manuals use `PERIPHERAL_REGISTER` names with an offset from the peripheral base address. Bit fields are named and numbered `[31:0]`. Access type abbreviations: `rw` (read/write), `r` (read-only), `w` (write-only), `rc_w1` (read, clear by writing 1).
