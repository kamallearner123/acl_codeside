## 31.1 Two Debug Protocols

| Feature | JTAG | SWD |
|---|---|---|
| Pins | TCK, TMS, TDI, TDO, (nTRST) | SWCLK, SWDIO (plus optional SWO) |
| Wires | 4-5 | 2 |
| Daisy chain | Yes, many devices | Single device per DP (multi-drop in newer spec) |
| Speed | Similar | Often faster per pin, with built-in error detection |
| Typical Cortex-M use | Boundary scan, multi-chip boards | Default for small MCUs |

Both reach the same debug port and the same CoreSight blocks. SWD is a two-pin alternative defined by Arm.

## 31.2 SWD Signals

- **SWCLK** is driven by the probe.
- **SWDIO** is bidirectional: requests from the probe, acknowledge and data from the target.
- **SWO** (optional) carries ITM trace out to the probe.
- **nRESET** lets the probe reset the target (connect under reset).

## 31.3 SWD Packet

```text One transaction
Request (8 bits): Start, APnDP, RnW, A[2:3], Parity, Stop, Park
Turnaround
ACK (3 bits): OK / WAIT / FAULT
Data (32 bits) + parity
```

A probe such as ST-LINK or J-Link hides all of this; you configure speed and the reset strategy.

## 31.4 Debug Port and Access Ports

The **DP** is the front door; **APs** are doors to buses. The AHB-AP lets the probe read and write memory while the core runs. Other APs reach APB peripherals and external DAPs.

## 31.5 Wiring Rules

| Rule | Why |
|---|---|
| Keep leads short, share ground | Prevents signal integrity errors |
| Pull-up on SWDIO, pull-down on SWCLK (usually in the probe) | Defined idle state |
| Do not repurpose SWD pins without care | You can lock yourself out |
| Use connect-under-reset | Recovers chips whose firmware disables SWD or sleeps |

> [warn] Bricked boards | If firmware reconfigures PA13/PA14 (SWDIO/SWCLK) the probe cannot connect. Hold NRST low while connecting, or use the BOOT0 system bootloader to reprogram.

## 31.6 Connectors and Probes

| Connector | Pins |
|---|---|
| Cortex Debug 10-pin 0.05 inch | VTref, SWDIO, SWCLK, SWO, nRESET, GND |
| 20-pin ARM JTAG | Legacy |
| Tag-Connect | Footprint only, saves board space |

Probes: ST-LINK, J-Link, CMSIS-DAP, Black Magic Probe.
